# Интерактивная карта лора Dota 2 — Техническое задание

| | |
|---|---|
| Версия | 0.1 (черновик) |
| Дата | 2026-11-11 |
| Статус | На согласовании |
| Референс | [map.leagueoflegends.com](https://map.leagueoflegends.com) |

---

## 1. Цель

Сделать интерактивную карту мира Dota 2: регионы, локации внутри регионов, герои, которые там живут, и лучшие официальные арты и синематики. По функциям и ощущению — аналог карты Runeterra для League of Legends, но в фирменной стилистике Dota 2.

Проект некоммерческий, фанатский. На сайте всегда виден дисклеймер о том, что проект не связан с Valve (см. §15).

## 2. Глоссарий

| Термин | Значение |
|---|---|
| **Мир** | Вся карта целиком, верхний уровень навигации. |
| **Регион** | Крупная область мира из лора (королевство, пустыня, море, план). Имеет границу-полигон, подсвечивается при наведении, по клику камера приближается. |
| **Ярус** | Особая область на краях карты для героев не из материального мира: **Верхний ярус** (небесные / до-мировые планы) у верхнего края, **Бездна** (адские планы) у нижнего. Механика как у региона. |
| **Локация** | Точка интереса внутри региона: деревня, город, крепость, руины, храм. Столица отмечается отдельно. |
| **Герой** | Герой Dota 2. Привязан к одному или нескольким местам (регионам / локациям) по лору. |
| **Сторона** | Radiant / Dire / Нейтрально — свойство региона, определяет цвет подсветки. |
| **Медиа** | Элемент галереи: официальный арт или видео с YouTube (синематик, трейлер). |
| **Нить** | Анимированная линия, которая связывает несколько мест одного героя. |

## 3. Объём

### 3.1 Входит в MVP
- Интро-экран, экран мира, экран региона, экран локации, модальное окно галереи.
- **Все** регионы и ярусы, которые есть в лоре; **все** известные по лору локации внутри них.
- Для каждого региона и локации: название, подзаголовок, описание, список героев.
- Медиа — только там, где есть официальный контент; **не более 3 медиа** на регион или локацию. Если контента нет, блок не показывается.
- Поиск героя с подсветкой его мест и нитями между ними.
- Внешние ссылки на официальные страницы героев.
- Подсветка регионов по стороне (Radiant / Dire / нейтрально).
- Атмосферные частицы по регионам (снег, пепел, туман и т. д.).
- Звуки клика и наведения, кнопка выключения звука.
- Переключение языка RU / EN.
- Адаптив: десктоп в приоритете, на мобильных нижняя шторка вместо правой панели.
- Деплой как статический сайт (приоритет — GitHub Pages).

### 3.2 Не входит в MVP (следующие итерации)
- Фоновая музыка и фоновый звук регионов.
- Объёмные (3D) ориентиры, если не успеем в MVP (см. §8.1).
- Свободная камера: перетаскивание, зум колесом.
- Админка для редактирования контента.

### 3.3 Сознательно не делаем
- Мини-карточку героя внутри карты: клик по герою сразу ведёт на официальную страницу.
- Общую страницу-индекс всех коллекций или всех героев.
- Собственные эмблемы для регионов, у которых их нет в лоре: показываем только название.

## 4. Структура мира

```
┌──────────────────────────────────────────────┐
│  ВЕРХНИЙ ЯРУС  (небесные / до-мировые планы)  │  ← звёзды, туманность
├──────────────────────────────────────────────┤
│                                              │
│      МАТЕРИКИ и ОСТРОВА  →  РЕГИОНЫ           │
│                    └→ ЛОКАЦИИ                 │
│                                              │
├──────────────────────────────────────────────┤
│  БЕЗДНА  (адские планы, Underscape и т. п.)   │  ← огненный разлом
└──────────────────────────────────────────────┘
```

- Ярусы входят в ту же картинку мира (полосы у верхнего и нижнего края), а не открываются отдельной страницей.
- Взаимное расположение регионов на материке задаём сами, опираясь на лор и фанатские карты (§9).
- Список регионов, локаций и привязку героев собираем на этапе исследования контента (эпик E1). В этом ТЗ они **не** фиксируются.

### 4.1 Привязка героев
- Герой привязан к тем местам, с которыми связан в своём лоре: месту рождения, дому, месту службы.
- У героя может быть несколько мест. Тогда он показывается в списках **каждого** из них, а при выборе героя места соединяются нитями (§6.6).
- Привязка возможна и к региону целиком (если конкретная локация неизвестна), и к локации.
- Герои, у которых место по лору не определено, живут в регионе **«Неизведанные земли»** — остров в тумане у края карты (решение В1, см. [E1-places.md](research/E1-places.md)).

### 4.2 Характеристики региона
Четыре поля в сетке 2×2, на двух языках. Если значение в лоре не найдено, пишем «Неизвестно».

| Поле | Примеры значений |
|---|---|
| Сторона | Radiant / Dire / Нейтрально |
| Власть | Монархия, Племена, Теократия, Нет власти |
| Отношение к магии | Почитают, Изучают, Запрещают, Боятся |
| Среда | Ледяная тундра, Пустыня, Лес, Море, Подземье, Иной план |

## 5. Экраны и состояния

### 5.1 Карта состояний

```
 S0 Интро ──[Начать]──▶ S1 Мир ──[клик по региону/ярусу]──▶ S2 Регион ──[клик по локации]──▶ S3 Локация
                        ▲  │                                  │  ▲                              │
                        │  └─ наведение → S1h подсказка        │  └────────[‹ Регион]────────────┘
                        └──────────────[‹ Мир / глобус]────────┘
 S2/S3 ──[клик по карточке медиа]──▶ S4 Галерея (модалка) ──[× / Esc]──▶ назад
 Любой экран ──[поиск героя]──▶ S5 Выбран герой (поверх текущего экрана)
```

| Переход | Как вызывается | Анимация (§7) |
|---|---|---|
| S0 → S1 | Кнопка «Начать» | A1 |
| S1 → S2 | Клик по региону (по полигону, медальону или названию) | A3 |
| S2 → S3 | Клик по маркеру или названию локации | A4 |
| S3 → S2 | «‹ Название региона» в панели; клик по пустому месту карты | A4, обратная |
| S2/S3 → S1 | Кнопка «глобус» на левой панели; хлебные крошки «‹ Мир» | A3, обратная |
| S2/S3 → S4 | Клик по карточке медиа | A6 |
| S4 → назад | ×, Esc, клик по затемнению | A6, обратная |
| Esc вне модалки | На уровень вверх: S3 → S2 → S1 | — |

Перейти в соседний регион напрямую из S2 нельзя: только через возврат в мир.

### 5.2 S0 — Интро
- Фон: карта мира, затянутая облаками, тёмная виньетка, низкое разрешение (быстрая загрузка).
- По центру: надзаголовок («Исследуй мир» / «Explore & discover»), крупное название мира (рабочее: **«Мир Dota 2» / «Dota 2 World»**, см. §17), декоративный разделитель, кнопка «Начать» / «Begin exploring».
- Пока грузятся ассеты мира, кнопка неактивна и показывает индикатор загрузки.
- Переключатель языка доступен уже на интро.

**Критерии приёмки:** интро отрисовывается до загрузки тяжёлых ассетов; клик по кнопке запускает A1 и попадает в S1; клик по кнопке включает звуки, если они не выключены пользователем.

### 5.3 S1 — Мир
- Карта целиком, верхний и нижний ярусы видны по краям.
- На каждом регионе и ярусе — название (заглавные буквы, засечный шрифт, тень). Эмблема-медальон есть только если она есть в лоре.
- Облака медленно дрейфуют по краям, виньетка.
- Камера статична: нельзя перетаскивать и зумить.

**S1h — наведение на регион:**
- Полигон региона заливается полупрозрачным цветом стороны (§8.3), граница светлеет.
- Название слегка увеличивается и светится.
- Рядом появляется подсказка: название, подзаголовок, до 6 портретов героев и плашка «+N», если героев больше. Портреты в подсказке не кликаются.
- Курсор — указатель.

**Критерии приёмки:** каждый регион и ярус подсвечивается по своему полигону без «дыр» и наложений; подсказка не выходит за край экрана; на тач-устройствах подсказки нет, тап сразу открывает регион.

### 5.4 S2 — Регион
**Карта:**
- Камера приближается к региону. Соседние регионы видны по краям, но затемнены и не кликаются.
- Маркеры локаций: точка с кольцом и подпись. Столица — звезда.
- Наведение на маркер: кольцо светится, подпись ярче, всплывает маленькая подсказка с портретами героев локации (если они есть).
- Частицы региона (§7.3).

**Правая панель** (ширина ~440–480 px, прокручивается):
1. Эмблема (если есть), название, подзаголовок.
2. Ряд портретов героев региона (включая героев его локаций), «+N» раскрывает весь список. Наведение на портрет — имя героя и нити к другим его местам (§6.6). Клик — официальная страница героя в новой вкладке.
3. Разделитель-ромб.
4. Сетка характеристик 2×2 (§4.2).
5. Описание (2–6 абзацев).
6. Ссылка «Подробнее ↗» на внешний источник (если есть).
7. Блок «Медиа в регионе»: до 3 карточек (картинка-фон, заголовок, подзаголовок/тип). Если медиа нет, блок скрыт.
8. Внизу хлебные крошки «‹ Мир».
- Панель сворачивается кнопкой-ромбом «›» на её левом краю.

**Критерии приёмки:** все локации региона видны без прокрутки карты; карточки медиа открывают S4 на нужном элементе; панель сворачивается и разворачивается без смещения карты.

### 5.5 S3 — Локация
- Камера сдвигается к локации (лёгкий сдвиг и дозум, §7). Активный маркер выделен, остальные остаются кликабельными.
- Панель меняет содержимое:
  1. Шапка-картинка с затуханием в фон (если есть арт локации).
  2. Название, тип («Прибрежное поселение», «Крепость»).
  3. Портреты героев локации (кликабельные).
  4. Описание.
  5. «Медиа в локации» — до 3 карточек (если есть).
  6. Внизу «‹ Название региона».
- Клик по другой локации переключает на неё сразу, без возврата в регион.

**Критерии приёмки:** локация без арта и медиа показывает только текст и героев, без пустых блоков и заглушек.

### 5.6 S4 — Галерея (модальное окно)
- Затемнение всего экрана.
- Слева медиа: картинка или встроенный плеер YouTube (`youtube-nocookie.com`), кнопка полноэкранного режима.
- Справа: счётчик «01 / 03», заголовок, подзаголовок (тип: «Арт», «Синематик», «Комикс»), описание, ссылка на источник ↗, автор или правообладатель.
- Листание: стрелки на экране, ← / → на клавиатуре, свайп на мобильных.
- Закрытие: ×, Esc, клик по затемнению. При закрытии видео останавливается.
- Комикс показывается одной страницей (решение владельца 2026-11-11): в карточке и в галерее метка «Комикс · отрывок», пояснение, что это одна страница, и заметная кнопка «Читать комикс целиком ↗» (новая вкладка, dota2.com на языке интерфейса). Картинка — на языке интерфейса.
- Листание идёт по кругу по медиа того региона или места, откуда открыта галерея.

### 5.7 S5 — Выбран герой (поиск)
См. §6.5–6.6.

## 6. Компоненты интерфейса

### 6.1 Левая панель (вертикальная)
Сверху вниз:
1. Логотип проекта → возврат на интро.
2. Глобус → мир (S1).
3. Лупа → поиск героя.
4. Переключатель языка RU / EN.
5. Внизу: звук вкл/выкл, «i» — о проекте (описание, дисклеймер, источники, благодарности авторам фан-карт).

### 6.2 Подсказка региона
Название, подзаголовок, до 6 портретов, «+N». Появляется с задержкой ~80 мс, следует за регионом, а не за курсором (позиция привязана к якорю региона).

### 6.3 Маркеры
| Тип | Вид |
|---|---|
| Название региона | Заглавные, засечный шрифт, тень, без эмблемы (или с эмблемой из лора) |
| Локация | Точка в кольце + подпись |
| Столица | Звезда в кольце + подпись крупнее |
| Ярус | Как регион, но с особым свечением (небесным / огненным) |

### 6.4 Хлебные крошки
Внизу панели: «‹ Мир» в S2, «‹ Регион» в S3.

### 6.5 Поиск героя
- Поле с автодополнением. Поиск по русскому и английскому именам и по распространённым сокращениям и прозвищам (`CM`, `AM`, `Пудж`, `Рики`), показывает портрет и имя.
- После выбора героя:
  - вверху появляется плашка выбранного героя (портрет, имя, ссылка ↗, ×);
  - все места героя подсвечиваются, а **все остальные регионы и локации приглушаются**;
  - **одно место** → камера летит к нему (S2 или S3);
  - **несколько мест** → камера показывает мир (или регион, если все места в одном регионе), места соединяются нитями, в плашке список мест — клик по месту ведёт к нему;
- × на плашке или Esc снимает выбор.
- Уточнено при реализации (E7): нашли по прозвищу — оно показывается рядом с именем; герой, привязанный к региону целиком, отмечается в регионе (нить идёт к его названию); поиск открывается лупой и закрывается Esc или уходом фокуса. Подробности — ARCHITECTURE A11.

### 6.6 Нити
- Появляются: при выборе героя в поиске; при наведении на портрет героя в панели (если у героя несколько мест).
- Вид: тонкая светящаяся пунктирная кривая (дуга, а не прямая), цвет — по стороне первого места, на концах — вспышка на маркере.
- Анимация «прорисовки» ~600 мс, затем медленное «течение» пунктира.
- Если второе место за пределами текущего кадра (в S2/S3), нить уходит за край экрана со стрелкой и названием места.
- Нить соединяет места героя по порядку его связей (первое — родина), а не каждое с каждым; метка у края кадра кликабельна и ведёт к месту.

### 6.7 Ссылки на героев
- Официальная страница героя на dota2.com, язык по текущему языку интерфейса. Формат URL проверяется при реализации (предположительно `https://www.dota2.com/hero/<slug>?l=russian|english`).
- Открывается в новой вкладке (`target="_blank" rel="noopener"`).

## 7. Анимации и эффекты

### 7.1 Таблица анимаций
| Код | Что | Длительность | Описание |
|---|---|---|---|
| A1 | Интро → мир | 1.5–2 с | Облака разъезжаются к краям, карта резко становится чёткой и слегка приближается (scale 1.08 → 1), интро-текст уходит вверх и исчезает. |
| A2 | Наведение на регион | 200 мс | Заливка и граница проявляются, название scale 1 → 1.05; подсказка — fade + сдвиг 8 px. |
| A3 | Мир ↔ регион | 1.0–1.4 с, ease-in-out | Камера приближается к рамке региона. Названия других регионов исчезают в первой трети; маркеры локаций появляются по очереди (шаг ~40 мс) в последней трети; панель выезжает справа (400 мс). Детальная картинка региона подменяет общую без «скачка» (кроссфейд). |
| A4 | Регион ↔ локация | 600–800 мс | Сдвиг камеры к локации и лёгкий дозум; содержимое панели — кроссфейд 250 мс. |
| A5 | Нити | 600 мс + цикл | Прорисовка по stroke-dashoffset, затем бесконечное течение пунктира. |
| A6 | Галерея | 250 мс | Затемнение — fade; медиа scale 0.96 → 1. |
| A7 | Облака в мире | цикл ~60 с | Медленный дрейф с параллаксом в 2–3 слоя. |

- Анимации камеры не прерываются кликами; клик во время анимации ставится в очередь или игнорируется.
- При `prefers-reduced-motion`: переходы камеры — мгновенный кроссфейд 200 мс, частицы и дрейф облаков выключены.

### 7.2 Hover и фокус
- Всё кликабельное меняет вид при наведении (свечение, цвет), курсор — указатель.
- Кнопки: тонкая металлическая рамка, при наведении — подсветка красным/бронзой.
- Фокус с клавиатуры виден (кольцо цвета акцента).

### 7.3 Частицы по регионам
Задаются в данных региона (`ambient`), рисуются на canvas поверх карты, только в S2/S3 (в мире — только облака).

| Тип | Пример применения |
|---|---|
| `snow` | Ледяные земли |
| `ash` / `embers` | Бездна, выжженные и вулканические земли |
| `fog` | Болота, руины, проклятые места |
| `rain` | Моря, побережья |
| `sparkles` / `stars` | Верхний ярус, магические места |
| `leaves` / `pollen` | Леса |
| `sand` | Пустыни |

Плотность — параметр. Бюджет — стабильные 60 FPS на среднем ноутбуке.

### 7.4 Звук (MVP)
- Короткие звуки: наведение на регион/локацию (тихий), клик, открытие панели, открытие галереи.
- Включаются после клика «Начать» (политика автовоспроизведения браузеров), можно выключить, выбор сохраняется в `localStorage`.
- Фоновая музыка и фоновый звук регионов — следующая итерация.

## 8. Визуальный стиль

### 8.1 Уровни исполнения карты
От лучшего к запасному. Выбираем лучший, который реально сделать:

| Уровень | Описание | Решение |
|---|---|---|
| **A** | Иллюстрированная карта + объёмные ориентиры (3D-модели или 2.5D-спрайты знаковых мест: цитадели, храмы, кристаллы) | Желательно, но может уйти в следующую итерацию |
| **B** | Качественная нарисованная карта с рельефом (как у LoL), детальные картинки регионов для приближения | **Целевой уровень MVP** |
| **C** | Стилизованная пергаментная карта (как фанатская «The Map of the Ancient») | Запасной вариант |

### 8.2 Палитра (фирменный стиль Dota 2)
Тёмный камень и сталь, бронза, красный акцент; Radiant и Dire — смысловые цвета. Точные значения подбираются в дизайн-задаче, ориентиры:

| Токен | Назначение | Ориентир |
|---|---|---|
| `--bg-0` | Фон, виньетка | почти чёрный с холодным оттенком |
| `--bg-1` | Панели | тёмный графит |
| `--metal` | Рамки, разделители | сталь / бронза |
| `--accent` | Акцент, кнопки, фокус | фирменный красный Dota |
| `--radiant` | Подсветка Radiant | зелёный / светлое золото |
| `--dire` | Подсветка Dire | тёмно-красный / огненный |
| `--neutral` | Подсветка нейтральных | холодный серо-голубой |
| `--text-1/2` | Текст | тёплый светлый / приглушённый |

### 8.3 Подсветка регионов
- По стороне: Radiant — зелёный, Dire — красный, нейтральные — нейтральный.
- Если сторона региона в лоре не определена — нейтральный.
- Ярусы: Верхний — светлое свечение, Бездна — огненное.

### 8.4 Типографика
- Заголовки и подписи на карте: засечный шрифт, заглавные, разрядка; на панели — заголовки жирные заглавные.
- Основной текст: читабельный гротеск.
- Фирменные шрифты Valve, скорее всего, использовать нельзя. Берём свободные аналоги с кириллицей (Google Fonts). Выбор — в дизайн-задаче.

### 8.5 Декор
- Срезанные углы у панелей и кнопок (как в интерфейсе Dota 2).
- Тонкие металлические линии с ромбами на концах как разделители.
- Кнопки-ромбы для «закрыть» и «свернуть панель».

## 9. Создание карты (ассеты)

1. **Исследование:** собрать все места из лора (эпик E1) и фанатские карты как референс:
   - [пост ВКонтакте с подборкой фанатских карт](https://vk.ru/wall-115027503_243167);
   - «The Map of the Ancient», Steam Workshop (пергаментная карта: Land of the Radiant, Scorch of the Dire, Thousand Tarns, Wailing Mountains, Temple of Mene, Home of the Keen Folk и др.).
2. **Схема расположения:** наброс-схема (блоками), где какой регион, кто с кем граничит, где море и острова, где ярусы. Согласуется с владельцем продукта до генерации.
3. **Генерация:** изображение мира по схеме (нейросеть + ручная доработка). Требования:
   - **на картинке нет текста** — все подписи накладываются в HTML (для RU/EN);
   - мир — не меньше 4096 px по ширине; для каждого региона — отдельная детальная картинка (≥ 2560 px) в той же стилистике;
   - в каждом регионе есть место под подписи и маркеры;
   - узнаваемая среда региона (лёд, пустыня, лес, лава).
4. **Разметка:** полигоны регионов (SVG-пути) и координаты локаций в единой системе координат (нормированные 0..1 относительно картинки мира).
5. **Оптимизация:** WebP/AVIF, превью низкого разрешения для интро.

## 10. Модель данных

Статичные JSON-файлы в репозитории. Все тексты — объект `{ "ru": "...", "en": "..." }`.

## 11. Контент

### 11.1 Источники (по приоритету)
1. Официальные биографии героев (dota2.com) и официальный лор Valve.
2. Комиксы Valve, страницы арканы/персон, официальные синематики и трейлеры (YouTube-канал Dota 2).
3. «DOTA: Dragon's Blood» (Netflix): **только кадры как медиа**; места и факты из сериала на карту не добавляем (решение В5).
4. Liquipedia, Dota 2 Wiki (Fandom) — для сверки и поиска мест.

### 11.2 Правила
- Лор региона и локаций — пересказ своими словами, не копирование текста источников.
- Медиа — только официальные арты и синематики, **только лучшее**, ≤ 3 на место. Видео встраиваются с YouTube, не перезаливаются.
- Нет контента — нет блока. Заглушки не показываем.
- У каждого региона хранится список источников (`sources`).

### 11.3 Портреты героев
Берутся с CDN Valve: копируем в репозиторий или ссылаемся напрямую (решается при реализации).

## 12. Локализация
- RU и EN, переключатель в левой панели и на интро.
- Язык по умолчанию — из языка браузера (`ru*` → RU, иначе EN), выбор сохраняется в `localStorage`.
- Имена героев — официальные в каждой локализации.
- Тексты интерфейса — в отдельном файле словаря.

## 13. Адаптивность

| Ширина | Поведение |
|---|---|
| ≥ 1280 | Основной макет: левая панель, карта, правая панель |
| 768–1279 | Правая панель уже, может перекрывать карту; сворачивается |
| < 768 | Правая панель → **нижняя шторка** (свёрнута ~30 % высоты, развёрнута ~90 %, жест «потянуть»); левая панель → компактная верхняя или нижняя полоса; наведения нет: тап по региону сразу открывает его; галерея на весь экран, свайп для листания |

## 14. Нефункциональные требования
- **Производительность:** интро отображается < 2 с на хорошем соединении; первая загрузка до старта мира ≤ ~3 МБ; детальные картинки регионов подгружаются заранее при наведении на регион; анимации камеры и частицы — 60 FPS на среднем ноутбуке.
- **Доступность:** навигация с клавиатуры (Tab по регионам и локациям, Enter — открыть, Esc — назад/закрыть), видимый фокус, `alt` у изображений, `prefers-reduced-motion`, контраст текста не ниже WCAG AA.
- **Браузеры:** две последние версии Chrome, Edge, Firefox, Safari; Яндекс Браузер.
- **Хостинг:** статический сайт без бэкенда. Приоритет — GitHub Pages, запасные варианты — Vercel или свой сервер.

## 15. Правовое
- Дисклеймер в окне «О проекте» и в подвале интро (RU и EN): некоммерческий фанатский проект, не связан с Valve Corporation и не одобрен ею; Dota 2 и связанные материалы — товарные знаки и собственность Valve.
- У каждого медиа указан правообладатель и ссылка на источник.
- Фанатские карты используются только как референс; авторы указываются в благодарностях.
