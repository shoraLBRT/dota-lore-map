# Интерактивная карта лора Dota 2 — Техническое задание

| | |
|---|---|
| Версия | 1.0 |
| Дата | 2026-11-19 |
| Статус | Действует |
| Референс | [map.leagueoflegends.com](https://map.leagueoflegends.com) |

---

## 1. Цель

Сделать интерактивную карту мира Dota 2: регионы, локации внутри регионов, герои, которые там живут, и лучшие официальные арты и синематики. По функциям и ощущению — аналог карты Runeterra для League of Legends, но в фирменной стилистике Dota 2.

Проект некоммерческий, фанатский. На сайте всегда виден дисклеймер о том, что проект не связан с Valve (см. §15).

## 2. Глоссарий

| Термин | Значение |
|---|---|
| **Мир** | Вся карта целиком, верхний уровень навигации. |
| **Регион** | Крупная область мира из лора (королевство, пустыня, море, план). Имеет границу-полигон, подсвечивается при наведении, по клику камера приближается. |
| **Ярус** | Особая область на краях карты для героев не из материального мира: **Верхний ярус** (небесные / до-мировые планы) у верхнего края, **Бездна** (адские планы) у нижнего. Механика как у региона. |
| **Локация** | Точка интереса внутри региона: деревня, город, крепость, руины, храм. Столица отмечается отдельно. |
| **Герой** | Герой Dota 2. Привязан к одному или нескольким местам (регионам / локациям) по лору. |
| **Сторона** | Radiant / Dire / Нейтрально — свойство региона, определяет цвет подсветки. |
| **Медиа** | Элемент галереи: официальный арт или видео с YouTube (синематик, трейлер). |
| **Нить** | Анимированная линия, которая связывает несколько мест одного героя. |

## 3. Объём

### 3.1 Входит в MVP
- Интро-экран, экран мира, экран региона, экран локации, модальное окно галереи.
- **Все** регионы и ярусы, которые есть в лоре; **все** известные по лору локации внутри них.
- Для каждого региона и локации: название, подзаголовок, описание, список героев.
- Медиа — только там, где есть официальный контент; **не более 3 медиа** на регион или локацию. Если контента нет, блок не показывается.
- Поиск героя с подсветкой его мест и нитями между ними.
- Внешние ссылки на официальные страницы героев.
- Подсветка регионов по стороне (Radiant / Dire / нейтрально).
- Атмосферные частицы по регионам (снег, пепел, туман и т. д.).
- Звуки клика и наведения, кнопка выключения звука.
- Переключение языка RU / EN.
- Адаптив: десктоп в приоритете, на мобильных нижняя шторка вместо правой панели.
- Деплой как статический сайт (приоритет — GitHub Pages).

### 3.2 Не входит в MVP (следующие итерации)
- Фоновая музыка и фоновый звук регионов.
- Объёмные (3D) ориентиры, если не успеем в MVP (см. §8.1).
- Админка для редактирования контента.

### 3.3 Сознательно не делаем
- ~~Мини-карточку героя внутри карты~~ — отменено: с E15 клик по герою открывает профиль (§6.8), ссылка на официальную страницу — внутри него.
- Общую страницу-индекс всех коллекций или всех героев.
- Собственные эмблемы для регионов, у которых их нет в лоре: показываем только название.

## 4. Структура мира

```
┌───────────────────────────────┐
│ море          НЕБЕСА  ПЛАНЫ ★ │  ← ближе к миру — небо, в углу — космос и Пустота
│                               │
│   СЕВЕРНЫЙ МАТЕРИК            │  Radiant и центр
│ ~~~~~~~~ пролив ~~~~~~~~      │
│   ЮЖНЫЙ МАТЕРИК      острова  │  Dire
│                               │
│ ✶ ПРЕИСПОДНИЕ  ПОДЗЕМЬЕ  море │  ← ближе к миру — пещеры, в углу — ад и загробье
└───────────────────────────────┘
```

- **Мир квадратный, 1:1** (решение владельца 2026-11-18, #163).
- **Два материка**, их разделяет пролив с запада на восток. Север — Radiant и центр. Юг — Dire: Ховен, Феллстрат, Империя Костей, Сверкающая пустошь, Друуд, Томо'кан, Стонущие горы, Тенистый берег. Относительные привязки лора между регионами сохраняются.
- **Ярусы — в углах** той же картинки мира, а не отдельной страницей. Правый верхний угол: ближе к миру — Небеса, дальше — космос, Планы и Пустота. Левый нижний: ближе к миру — Подземье, дальше — Преисподние и загробье. Два других угла — открытое море.
- Взаимное расположение регионов на материке задаём сами, опираясь на лор и фанатские карты (§9).
- Список регионов, локаций и привязку героев собираем на этапе исследования контента (эпик E1). В этом ТЗ они **не** фиксируются.

### 4.1 Привязка героев
- Герой привязан к тем местам, с которыми связан в своём лоре: месту рождения, дому, месту службы.
- У героя может быть несколько мест. Тогда он показывается в списках **каждого** из них, а при выборе героя места соединяются нитями (§6.6).
- Привязка возможна и к региону целиком (если конкретная локация неизвестна), и к локации.
- Герои, у которых место по лору не определено, живут в регионе **«Неизведанные земли»** — остров в тумане у края карты (решение В1, см. [E1-places.md](research/E1-places.md)).

### 4.2 Характеристики региона
Четыре поля в сетке 2×2, на двух языках. Если значение в лоре не найдено, пишем «Неизвестно».

| Поле | Примеры значений |
|---|---|
| Сторона | Radiant / Dire / Нейтрально |
| Власть | Монархия, Племена, Теократия, Нет власти |
| Отношение к магии | Почитают, Изучают, Запрещают, Боятся |
| Среда | Ледяная тундра, Пустыня, Лес, Море, Подземье, Иной план |

## 5. Экраны и состояния

### 5.1 Карта состояний

```
 S0 Интро ──[Начать]──▶ S1 Мир ──[клик по региону/ярусу]──▶ S2 Регион ──[клик по локации]──▶ S3 Локация
                        ▲  │                                  │  ▲                              │
                        │  └─ наведение → S1h подсказка        │  └────────[‹ Регион]────────────┘
                        └──────────────[‹ Мир / глобус]────────┘
 S2/S3 ──[клик по карточке медиа]──▶ S4 Галерея (модалка) ──[× / Esc]──▶ назад
 Любой экран ──[поиск героя / клик по герою]──▶ S5 Профиль героя (панель поверх текущего экрана, §6.8)
```

| Переход | Как вызывается | Анимация (§7) |
|---|---|---|
| S0 → S1 | Кнопка «Начать», клик в любом месте интро, `Enter` / `Space` | A1 |
| S1 → S2 | Клик по региону (по полигону, медальону или названию) | A3 |
| S2 → S3 | Клик по маркеру или названию локации | A4 |
| S3 → S2 | «‹ Название региона» в панели; клик по пустому месту карты | A4, обратная |
| S2/S3 → S1 | Кнопка «глобус» на левой панели; хлебные крошки «‹ Мир» | A3, обратная |
| S2/S3 → S4 | Клик по карточке медиа | A6 |
| S4 → назад | ×, Esc, клик по затемнению | A6, обратная |
| Esc вне модалки | На уровень вверх: S3 → S2 → S1 | — |

Перейти в соседний регион напрямую из S2 нельзя: только через возврат в мир.

### 5.2 S0 — Интро
- Фон: карта мира, приглушённая и слегка размытая (4 px), материки узнаются; облака только по краям, без белых пятен за текстом; тёмная виньетка, низкое разрешение (быстрая загрузка). На телефоне фон — арт мира на весь экран (#187).
- В мир ведёт клик в любом месте экрана (кроме переключателя языка), `Enter` или `Space`; кнопка «Начать» — видимая подсказка и цель для клавиатуры (#187).
- В подвале — дисклеймер одной строкой на языке интерфейса.
- По центру: надзаголовок («Исследуй мир» / «Explore & discover»), крупное название мира (рабочее: **«Мир Dota 2» / «Dota 2 World»**, см. §17), декоративный разделитель, кнопка «Начать» / «Begin exploring».
- Пока грузятся ассеты мира, кнопка неактивна и показывает индикатор загрузки.
- Переключатель языка доступен уже на интро.

**Критерии приёмки:** интро отрисовывается до загрузки тяжёлых ассетов; клик по кнопке запускает A1 и попадает в S1; клик по кнопке включает звуки, если они не выключены пользователем.

### 5.3 S1 — Мир
- Арт мира — на весь кадр, без фона вокруг (решение владельца 2026-11-18, #165): при отдалении до упора мир покрывает кадр, ярусы в углах могут быть срезаны краем экрана.
- На каждом регионе и ярусе — название (заглавные буквы, засечный шрифт, тень). Эмблема-медальон есть только если она есть в лоре.
- Облака медленно дрейфуют по краям, виньетка.
- **Свободная камера** (#165): карту тянут мышью или пальцем (с инерцией), приближают колесом вокруг курсора, щипком, двойным кликом по морю (Shift — отдалить), клавишами `+`/`−`, стрелки двигают, `0` — весь мир; кнопки «+», «−», «весь мир» справа внизу (на телефоне — щипок). Зум — от «мир во весь кадр» до 3× (ближе ~1 px арта на 1 px экрана — нет); щелчок колеса — ×1.2, не больше щелчка за событие и за 120 мс (тачпад не разгоняет), кнопки и клавиши — ×1.3 (#179); кадр региона — не ближе 2.5×, места — 2.5 × 1.15; за край мира камера не уходит. Перетаскивание — не клик: регион и место после него не открываются. Подписи регионов и маркеры не растут с приближением. Перелёты к региону и месту (§7.1) работают поверх: после перелёта карту можно двигать дальше, «‹ Мир» возвращает к общему виду. На телефоне в мире — список регионов под вписанной картой (#39), свободная камера — в регионе и месте.

**S1h — наведение на регион:**
- Полигон региона заливается полупрозрачным цветом стороны (§8.3), граница светлеет.
- Название слегка увеличивается и светится.
- Рядом появляется подсказка: название, подзаголовок, до 6 портретов героев и плашка «+N», если героев больше (§6.2). В подсказку можно зайти мышью и с клавиатуры: портрет выбирает героя, «+N» раскрывает весь список (#65).
- Курсор — указатель.

**Критерии приёмки:** каждый регион и ярус подсвечивается по своему полигону без «дыр» и наложений; подсказка не выходит за край экрана; на тач-устройствах подсказки нет, тап сразу открывает регион.

### 5.4 S2 — Регион
**Карта:**
- Камера приближается к региону. Соседние регионы видны по краям, но затемнены и не кликаются.
- Маркеры локаций: точка с кольцом и подпись. Столица — звезда.
- Наведение на маркер: кольцо светится, подпись ярче, всплывает маленькая подсказка с портретами героев локации (если они есть).
- Частицы региона (§7.3).

**Правая панель** (ширина ~440–480 px, прокручивается):
1. Эмблема (если есть), название, подзаголовок.
2. Ряд портретов героев региона (включая героев его локаций), «+N» раскрывает весь список. Наведение на портрет — имя героя, его места на карте и нити к другим его местам (§6.6). Клик — официальная страница героя в новой вкладке.
3. Разделитель-ромб.
4. Сетка характеристик 2×2 (§4.2).
5. Описание (2–6 абзацев).
6. Ссылка «Подробнее ↗» на внешний источник (если есть).
7. Блок «Места» (#99): строки-кнопки (≥ 44 px) — значок значимости как у маркера (§6.3: столица, место события, обычное, второстепенное), название, тип, число героев, значок медиа. Порядок: столица, места событий, обычные, второстепенные, внутри — по алфавиту языка. Видны первые 8, остальные — кнопкой «Все места (N)». Нажатие — как клик по маркеру; наведение и фокус на строке дают маркеру вид наведения (без подсказки героев). Региона без мест — блока нет. В панели места списка нет: назад ведёт крошка.
8. Блок «Медиа в регионе»: до 3 карточек (картинка-фон, заголовок, подзаголовок/тип). Если медиа нет, блок скрыт.
9. Хлебные крошки «‹ Мир» — в шапке панели, сверху слева, рядом с кнопкой «Свернуть»; видны без прокрутки (§6.4).
- Панель сворачивается кнопкой-ромбом «›» на её левом краю.

**Критерии приёмки:** все локации региона видны без прокрутки карты; карточки медиа открывают S4 на нужном элементе; панель сворачивается и разворачивается без смещения карты.

### 5.5 S3 — Локация
- Камера сдвигается к локации (лёгкий сдвиг и дозум, §7). Активный маркер выделен, остальные остаются кликабельными.
- Панель меняет содержимое:
  1. Шапка-картинка с затуханием в фон (если есть арт локации).
  2. Название, тип («Прибрежное поселение», «Крепость»).
  3. Портреты героев локации (кликабельные).
  4. Описание.
  5. «Медиа в локации» — до 3 карточек (если есть).
  6. В шапке панели — «‹ Название региона» (§6.4).
- Клик по другой локации переключает на неё сразу, без возврата в регион.

**Критерии приёмки:** локация без арта и медиа показывает только текст и героев, без пустых блоков и заглушек.

### 5.6 S4 — Галерея (модальное окно)
- Затемнение всего экрана.
- Слева медиа: картинка или встроенный плеер YouTube (`youtube-nocookie.com`), кнопка полноэкранного режима.
- Справа: счётчик «01 / 03», заголовок, подзаголовок (тип: «Арт», «Синематик», «Комикс»), описание, ссылка на источник ↗, автор или правообладатель.
- Листание: стрелки на экране, ← / → на клавиатуре, свайп на мобильных.
- Закрытие: ×, Esc, клик по затемнению. При закрытии видео останавливается.
- Комикс показывается одной страницей (решение владельца 2026-11-11): в карточке и в галерее метка «Комикс · отрывок», пояснение, что это одна страница, и заметная кнопка «Читать комикс целиком ↗» (новая вкладка, dota2.com на языке интерфейса). Картинка — на языке интерфейса.
- Листание идёт по кругу по медиа того региона или места, откуда открыта галерея.

### 5.7 S5 — Выбран герой (поиск)

## 6. Компоненты интерфейса

### 6.1 Левая панель (вертикальная)
Сверху вниз:
1. Логотип проекта → возврат на интро.
2. Глобус → мир (S1).
3. Лупа → поиск героя.
4. Переключатель языка RU / EN.
5. Внизу: обратная связь (§6.9), звук вкл/выкл, «i» — о проекте (описание, дисклеймер, источники, благодарности авторам фан-карт, строка про обратную связь и публичность сообщений).

### 6.2 Подсказка региона
Название, подзаголовок, до 6 портретов, «+N». Появляется с задержкой ~80 мс, следует за регионом, а не за курсором. Встаёт рядом с габаритом региона на экране, а не на нём (#101): справа, слева, снизу или сверху — первая сторона, где подсказка целиком в окне и правее левой панели; сбоку — на высоте названия, снизу и сверху — под или над ним. Ни одна сторона не подошла — у названия, с прижатием к краю окна.

Подсказка — рабочая (#65; мир, десктоп и планшет с мышью; на телефоне её нет, там список регионов §13):
1. Остаётся открытой, пока мышь на регионе **или на подсказке**; уходит через ~200 мс после того, как мышь ушла с обоих, — хватает, чтобы перевести мышь с региона на подсказку и обратно. Мышь на другом регионе — подсказка сразу переходит на него; исключение — сосед на пути к подсказке (мышь движется к ней): он перехватывает подсказку, только если мышь задержалась на нём ~200 мс или свернула в сторону.
2. Портрет — кнопка: открывает профиль героя справа (§6.8: `?hero=`, приглушение, нити), **камера остаётся в мире** — даже если у героя одно место или один регион.
3. «+N» раскрывает весь список героев в той же подсказке, без перехода в регион. Подсказка при этом остаётся на месте и только вдвигается внутрь окна; ушла на другой регион — снова свёрнута.
4. Под портретами — подпись: имя героя под курсором или фокусом, иначе «Нажмите на героя — он появится на карте».
5. Клавиатура: Tab с региона ведёт в его подсказку, Tab с последней кнопки — к следующему региону, Shift+Tab с первой — обратно на регион. Esc в подсказке или на регионе закрывает подсказку (фокус — на регионе; Esc не снимает героя и не уводит уровнем выше); подсказка вернётся, когда фокус снова придёт на регион или мышь — на него.
6. Клик по самому региону, как и раньше, открывает регион. Клик мышью по подсказке не ставит в неё фокус — иначе она держалась бы открытой после ухода мыши.
7. Регион без героев и без медиа — подсказка без кнопок (только название и подзаголовок), в неё не заходят.
8. Значок медиа (#69, §6.3) — кнопка справа от названия: значок и вид медиа («комикс»), если медиа есть у региона или у его мест. Он первый по Tab в подсказке.

### 6.3 Маркеры
| Тип | Вид |
|---|---|
| Название региона | Заглавные, засечный шрифт, тень, без эмблемы (или с эмблемой из лора) |
| Локация | Точка в кольце + подпись |
| Место события (#68) | Как локация, но кольцо ярче и толще, подпись светлее |
| Второстепенное место (#68) | Кольцо и точка меньше и тусклее, подпись мельче; маркер на карте и кликается |
| Столица | Звезда в кольце + подпись крупнее |
| Ярус | Как регион, но с особым свечением (небесным / огненным) |
| Значок медиа (#69) | Квадратик-страница с панелями комикса в **верхнем правом углу кольца** маркера места — между кольцом и подписями сверху и справа (`labels.ts`); в подсказке региона — кнопка «значок + вид медиа» у названия (§6.2 п. 8) |

**Значимость мест** (#68) — по данным, без ручной разметки (правило — ARCHITECTURE A3, считает `build-data`): **место события** — у героя тут событие пути (родился, жил, путь, сражался, служил, изгнан, погиб, бывал), место — остановка его `path`, тут происходит действие медиа места или это столица; **второстепенное** — только упоминание (`mention`) или героев нет. Других уровней нет (#115). Тусклость — цветом, не прозрачностью: кольцо второстепенного места ≥ 3:1 к фонам (WCAG 1.4.11), подпись ≥ 4.5:1. Подписи ставятся по важности: места событий раньше, второстепенные последними — им первым прятаться до наведения (`labels.ts`, A4). Наведение, фокус, выбор места и подсветка героя (§6.5) выглядят у всех мест одинаково.

**Значок медиа** (#69) ставится, если у места есть `media` (`content/media.json`); в подсказке региона — если медиа есть у региона или у любого его места. Это отдельная кнопка сразу за маркером (Tab: место → его значок), имя для диктора — «Есть медиа: комикс» / «Media: comic» (виды медиа по подзаголовкам, строчными, без повторов). Клик или Enter открывает галерею (§5.6, `?media=`) **на экране, которому медиа принадлежит**: у места — экран места (камера летит к нему под галереей, закрытие оставляет в месте); в подсказке региона — экран региона и его первое медиа, а если своего нет — экран первого места с медиа. Выбранный герой (`?hero=`) сохраняется. Верхний правый угол маркера занят этим значком: значимость мест (#68) меняет размер и яркость самого маркера, значок масштабируется вместе с кольцом; значки событий (#67) ставятся на нить или в другое место у точки, не в этот угол. На телефоне подсказки региона нет — медиа региона видно в его панели.

### 6.4 Хлебные крошки
В шапке панели, сверху слева, рядом с кнопкой «Свернуть»: «‹ Мир» в S2, «‹ Регион» в S3. Шапка не прокручивается вместе с текстом — кнопка видна всегда; на телефоне она вверху шторки, сразу под ручкой. По Tab — после «Свернуть» и до содержимого. При смене экрана кнопка уходит вместе с содержимым, и фокус ставится туда, откуда пришли (§14): из места в регион — на маркер места.

### 6.5 Поиск героя, региона и места
- Поле с автодополнением. Поиск по русскому и английскому именам и по распространённым сокращениям и прозвищам (`CM`, `AM`, `Пудж`, `Рики`), показывает портрет и имя.
- Поиск находит и регионы, и места по названию на обоих языках (#100): «icew» в русском интерфейсе — Айсрак. Варианты группами — герои, регионы, места; всего не больше 8, героев не меньше 4, если они есть. Регион — ромб цвета стороны и название, место — значок маркера, название и регион. Выбор региона или места открывает его экран, выбранного героя не трогает; подпись поля — «Герой, регион или место».
- После выбора героя:
  - справа открывается профиль героя (§6.8); профиль закрыт, а герой выбран — вверху чип героя (портрет, имя, ✕);
  - все места героя подсвечиваются, а **все остальные регионы и локации приглушаются**;
  - **одно место** → камера летит к нему (S2 или S3);
  - **несколько мест** → камера показывает мир (или регион, если все места в одном регионе), места соединяются нитями, в профиле список мест — клик по месту ведёт к нему;
- Крошка «назад» в профиле или Esc закрывают профиль, второй Esc или ✕ на чипе снимают выбор.
- Уточнено при реализации (E7): нашли по прозвищу — оно показывается рядом с именем; герой, привязанный к региону целиком, отмечается в регионе (нить идёт к его названию); поиск открывается лупой и закрывается Esc или уходом фокуса. Подробности — ARCHITECTURE A11.

### 6.6 Нити
- Появляются: при выборе героя в поиске; при наведении на портрет героя в панели (если у героя несколько мест).
- Вид: светящаяся кривая (дуга, а не прямая) в тёмном канте, цвет — по стороне первого места, на концах — вспышка на маркере. Рисунок шага пути (#168) — лента с сужением к концу или караванная штриховка, на конце — наконечник-«перо» в стиле карты, остриё у места, куда ведёт шаг (выбор варианта — за владельцем, ARCHITECTURE A11). Пока на карте нити, облака над картой расходятся. В мире на телефоне (< 768 px) вспышка и значок события — в 0.6 размера, значки — только у шагов пути: регионы там мелкие, и иначе значки закрывали бы их подписи (#102, #168).
- Нити со смыслом (#67): **шаг пути** героя — сплошная нить со стрелкой «откуда → куда» по порядку; **прочая связь** (герой там не был — упоминание, или тип связи ещё не уточнён) — пунктир без стрелки. На нити — значок события места, куда она ведёт (родина, дом, путь, сражение, служба, изгнание, гибель, бывал, упоминание; у связи без типа значка нет). Значок не встаёт на подписи регионов и мест, под панель и плашку героя; нет свободного места на нити или нить короче ~56 px — значка нет (событие всё равно видно в плашке). Те же значки — у мест в плашке героя (подсказка — название события); в плашке — раскрывающаяся легенда «Как читать нити»: виды линий и события этого героя, RU/EN.
- Анимация (#168): путь прорисовывается шаг за шагом по порядку остановок (~600 мс на шаг, длинный путь быстрее, весь — не дольше ~2.4 с), прочие связи — после пути; вспышка места — когда нить до него дошла, значки и наконечники проявляются к концу своего шага; по дорисованному шагу время от времени пробегает светящаяся точка. Плавно (easing), без рывков. Reduced motion — нить сразу целиком, без бегущей точки, течения и проявления.
- Если второе место за пределами текущего кадра (в S2/S3), нить уходит за край экрана со стрелкой и названием места. Если место в другом регионе — второй строкой регион (не повторяется, если место называется так же). Метка всегда целиком в видимой части кадра: правее левой полосы, левее панели, ниже плашки героя или поиска, на телефоне — выше шторки; метки не налезают друг на друга (#64).
- Нить соединяет места героя по порядку его связей (первое — родина), а не каждое с каждым; метка у края кадра кликабельна и ведёт к месту. Какие места — шаги пути, а какие — прочие связи, решает ARCHITECTURE A11.
- Наведение или фокус на героя **всегда** показывает, где он, даже если место одно и нитей нет (#66). Герой — портрет в панели или текущий вариант поиска (стрелки, курсор). В мире подсвечиваются его регионы, как при наведении на регион; в регионе и месте его маркеры светятся и от кольца расходится пульс; место за кадром без нити к нему получает такую же метку у края — по лучу из центра видимой части кадра (сам открытый регион, если связь с ним целиком, меткой не отмечается). Мышь, фокус с клавиатуры и тап — одинаково; после тапа герой остаётся на карте, пока не тронут другой портрет, фокус не уйдёт или не сменится экран (сам тап по-прежнему открывает страницу героя, §6.7). Reduced motion — без пульса, только подсветка маркера.

### 6.7 Ссылки на героев
- Официальная страница героя на dota2.com, язык по текущему языку интерфейса. С E15 (§6.8) ссылка — внутри профиля героя, а клик по портрету открывает профиль. Формат URL проверяется при реализации (предположительно `https://www.dota2.com/hero/<slug>?l=russian|english`).

### 6.8 Профиль героя (E15, #61)
- **Где.** Правая панель поверх панели текущего экрана; на телефоне — та же шторка (§13), в свёрнутом виде видны шапка и имя. Свёрнутая на компьютере панель профиля — ромб, как у региона.
- **Как открыть.** Клик по герою где угодно: портрет в панели региона или места, портрет в подсказке региона в мире (§6.2), герой в «Связан с» другого профиля; выбор в поиске (§6.5). Портрет в подсказке места (наведение на маркер) не кликается — тап по маркеру сразу открывает место.
- **Камера.** Клик по герою камеру не двигает: из мира она **не приближается** — профиль справа, регионы героя подсвечены, нити на карте; на компьютере и планшете карта целиком отодвигается в свободную часть слева от профиля (уменьшаясь, если нужно), свернули профиль — снова на весь кадр, переход — обычная анимация камеры (#97); на телефоне профиль в шторке, карта не меняется; из региона или места — как раньше: маркеры героя светятся, нити уходят за край с метками. Поиск по-прежнему ведёт камеру к месту героя (§6.5).
- **Адрес** (A5, A15): `?hero=<key>&profile` — профиль открыт; `?hero=<key>` — герой только выбран (подсветка, нити, чип). Профиль закрывают кнопка в шапке «‹ Закрыть профиль» / «‹ Close profile» (возвращает панель экрана под профилем), Esc и «назад» браузера — герой остаётся выбранным. Esc по порядку: галерея → поиск → профиль → выбранный герой → уровень вверх.
- **Переход на другой экран** при открытом профиле — маркер, регион, крошка, место из списка профиля, метка «нить за краем», клавиатура — показывает панель того места или региона, куда пришли; профиль закрывается, герой остаётся выбранным: нити и метки «за краем» на месте.
- **Чип героя** — пока герой выбран, а профиль закрыт: вверху карты, по центру свободной части (на телефоне — над картой и списком регионов): портрет, имя и «Профиль героя» — кнопка, открывает профиль снова; ✕ снимает выбор. RU/EN, клавиатура, кнопки не ниже 44 px.
- **Содержимое** (пустые блоки не рисуются, партии E14 идут постепенно):
  1. Шапка — широкий портрет Valve; имя; ссылка «dota2.com ↗» (§6.7).
  2. Описание своими словами RU/EN (`profile.summary`, партии E14).
  3. «Места героя» — по порядку пути: значок и название события, место, регион; прочие связи (упоминание, тип не уточнён) — пунктирная полоса, как пунктирная нить. Клик ведёт к месту, герой остаётся выбранным. Под списком — легенда «Как читать нити» (§6.6). Сразу под описанием: главное в профиле для карты (#95).
  4. «Арты» — карточки, клик открывает галерею (§5.6) с артами героя: рендер Valve в полный рост, `profile.art`, официальные комиксы, где герой есть (A6).
  5. «Связан с» — портрет, имя, кем приходится (союзник, враг, соперник, родня, возлюбленные, наставник, ученик, господин, слуга). Связи берутся и из записей других героев (обратные: наставник ↔ ученик, господин ↔ слуга). Клик открывает профиль того героя, наведение и фокус показывают его на карте (§6.6).
- **Фокус** (§14): при открытии профиля и смене героя — на имя героя; при закрытии — на заголовок панели экрана, а в мире без панели — на чип героя.

### 6.9 Обратная связь (E17, #73, #74)
- **Кнопка** «Обратная связь» / «Feedback» — облачко реплики в левой панели внизу, над звуком (§6.1); на телефоне — в полосе сверху. Подпись — подсказка, она же доступное имя.
- **Окно** — небольшое, в углу у кнопки (на компьютере — внизу слева рядом с панелью, на телефоне — под полосой во всю ширину с полями), без затемнения карты. Внутри: заголовок; пояснение «Отзыв, пожелание или ошибка — всё пригодится. Сообщение будет опубликовано открыто на GitHub, не пишите личных данных» и что для отправки нужен аккаунт GitHub; поле «Сообщение» со счётчиком «N / 1000» (потолок 1000 символов, как в Transliterator); «Отправить ↗».
- **Закрытие** — ×, Esc, клик вне окна, повторный клик по кнопке. Черновик не теряется: хранится в `localStorage`, переживает закрытие и перезагрузку; нет хранилища — живёт, пока открыта страница.
- **Esc** закрывает окно первым: профиль, выбранный герой и экран остаются (порядок Esc — ARCHITECTURE A11).
- **Отправка, шаг 1** (как H1 в Transliterator): «Отправить» — ссылка, открывающая в новой вкладке форму нового issue репозитория с заполненными заголовком, текстом и меткой `feedback`. Без серверов, работает на GitHub Pages. Создаёт issue сам пользователь, на GitHub. После клика поле очищается, окно пишет, что форма открыта в новой вкладке. Пустое сообщение не отправить.
- **Формат issue** (`features/feedback/message.ts`, A16): заголовок «Отзыв с карты: <первая строка>» (EN — «Feedback from the map: …»); текст — сообщение, затем «Контекст»: адрес, экран, регион, место, герой (и открыт ли профиль), медиа, версия сборки, язык; подпись «Отправлено кнопкой обратной связи». Язык подписей — язык интерфейса.
- **«Нашли ошибку?» у блоков (#74).** В конце панели региона, панели места, профиля героя и описания медиа в галерее — одна строка мелким текстом «Нашли ошибку или знаете больше? Расскажите» / «Spotted a mistake or know more? Tell us» (кнопка, приглушённый цвет, подчёркивание). Ничего не перекрывает и не спорит с содержимым; на телефоне — последняя строка шторки, цель касания 44 px в высоту. Есть у каждого такого блока, даже пустого (у места без текста она нужнее всего).
- Строка открывает **то же окно**, уже привязанное к блоку: под заголовком «Регион: Айсрак» (Место / Герой / Медиа; EN — Region / Place / Hero / Media), переключатель «Что это»: «Ошибка» (выбрана сразу) / «Дополнение» / «Другое» (EN — Mistake / Addition / Other), подсказка в поле — по виду. Общая кнопка левой панели открывает окно без блока и без переключателя. Черновик один на все блоки (не теряется при переходе к другому блоку); вид сбрасывается на «ошибку» при каждом открытии. Из галереи окно открывается поверх неё; пока оно открыто, стрелки не листают галерею, Esc закрывает сначала окно.
- **Issue отзыва о блоке**: заголовок по виду — «Ошибка в «<название>»: …», «Дополнение к «<название>»: …», «Отзыв о «<название>»: …» (EN — Mistake in “…”: …, Addition to “…”: …, Feedback on “…”: …); название — на языке интерфейса, не длиннее 60 символов, свои кавычки названия («Новые соседи») не удваиваются. В контексте сразу после адреса — «Блок: регион Айсрак (`icewrack`)» (тип блока и id в данных: регион, `<регион>/<место>`, ключ героя, id медиа) и «Вид: ошибка». Метки — `feedback` и `content-fix` при любом виде (отзыв относится к контенту).
- **Длина ссылки** ограничена (A16): сообщение не сокращается никогда — при нехватке места уходят строки контекста, затем выдержка в заголовке. Если не помещается и само сообщение (иероглифы, эмодзи), «Отправить» неактивна и окно просит сократить текст.
- **Метки `feedback` и `content-fix`**: GitHub подставляет метки из ссылки только тем, у кого есть права triage в репозитории; у остальных issue создаётся без меток — их ставит владелец. Ни на что, кроме удобства, метки не влияют.
- Доступность (§14): ловушка фокуса в окне, фокус при открытии — в поле, при закрытии — на кнопку (если клик вне окна не увёл его на другой элемент); цели касания на телефоне — 44 px; при reduced motion окно появляется без сдвига.
- Следующий шаг E17: отправка без аккаунта GitHub через функцию Cloudflare и Turnstile (#75).

## 7. Анимации и эффекты

### 7.1 Таблица анимаций
| Код | Что | Длительность | Описание |
|---|---|---|---|
| A1 | Интро → мир | 1.5–2 с | Облака разъезжаются к краям, тот же арт становится чётким и камера слегка отъезжает (scale 1.08 → 1), интро-текст уходит вверх и исчезает; подписи регионов проявляются после арта каскадом (`--dur-stagger`). |
| A2 | Наведение на регион | 200 мс | Заливка и граница проявляются, название scale 1 → 1.05; подсказка — fade + сдвиг 8 px. |
| A3 | Мир ↔ регион | 1.0–1.4 с, ease-in-out | Камера приближается к рамке региона. Названия других регионов исчезают в первой трети; маркеры локаций появляются по очереди (шаг ~40 мс) в последней трети; панель выезжает справа (400 мс). Детальная картинка региона подменяет общую без «скачка» (кроссфейд). |
| A4 | Регион ↔ локация | 600–800 мс | Сдвиг камеры к локации и лёгкий дозум; содержимое панели — кроссфейд 250 мс. |
| A5 | Нити | 600 мс + цикл | Прорисовка по stroke-dashoffset, затем бесконечное течение пунктира. |
| A6 | Галерея | 250 мс | Затемнение — fade; медиа scale 0.96 → 1. |
| A7 | Атмосфера карты (#167) | цикл 48–84 с | Облака над морем и у ярусов на трёх высотах дрейфуют и при движении камеры смещаются с параллаксом; туман над Неизведанными землями, разломом Глубин и Подземьем, дымка над морем, свечение звёзд и лавы, зерно. Сила растёт с приближением: весь мир почти чистый. |

- Анимации камеры не прерываются кликами; клик во время анимации ставится в очередь или игнорируется.
- При `prefers-reduced-motion`: переходы камеры — мгновенный кроссфейд 200 мс, частицы, дрейф и параллакс облаков, пульс свечения выключены (атмосфера A7 стоит вместе с картой).

### 7.2 Hover и фокус
- Всё кликабельное меняет вид при наведении (свечение, цвет), курсор — указатель.
- Кнопки: тонкая металлическая рамка, при наведении — подсветка красным/бронзой.
- Фокус с клавиатуры виден (кольцо цвета акцента).

### 7.3 Частицы по регионам
Задаются в данных региона (`ambient`), рисуются на canvas поверх карты, только в S2/S3 (в мире — только атмосфера A7).

| Тип | Пример применения |
|---|---|
| `snow` | Ледяные земли |
| `ash` / `embers` | Бездна, выжженные и вулканические земли |
| `fog` | Болота, руины, проклятые места |
| `rain` | Моря, побережья |
| `sparkles` / `stars` | Верхний ярус, магические места |
| `leaves` / `pollen` | Леса |
| `sand` | Пустыни |

Плотность — параметр. Бюджет — стабильные 60 FPS на среднем ноутбуке.

### 7.4 Звук (MVP)
- Короткие звуки: наведение на регион/локацию (тихий), клик, открытие панели, открытие галереи.
- Включаются после клика «Начать» (политика автовоспроизведения браузеров), можно выключить, выбор сохраняется в `localStorage`. Если пришли по прямой ссылке мимо интро, звук включает первый клик или клавиша.
- Звуки синтезируются в браузере (ARCHITECTURE A12) — без файлов и сторонних лицензий.
- Фоновая музыка и фоновый звук регионов — следующая итерация.

### 7.5 Правило движения (#170)
- Анимируются только `transform` и `opacity` (плюс цвет, тень и `filter` при наведении). Размеры и отступы (`width`, `height`, `top`, `right`, `margin`…) не анимируются — раскладка не пересчитывается на каждом кадре; это проверяет `quality.test.ts`. Скачок поля по задержке (`0s`) — не анимация.
- Длительности и кривые — только токены (`tokens.css`): `--dur-hover` 200, `--dur-fade` 250, `--dur-panel` 400, `--dur-place` 700, `--dur-camera` 1200, `--dur-intro` 1800 мс, шаг каскада `--dur-stagger` 40 мс, «дыхание» `--dur-breathe` 3,2 с. Кривые: `--ease-out` — появление и наведение, `--ease-in-out` — камера (и в WAAPI) и смена кадра, `--ease-spring` — то, что выезжает и встаёт на место с лёгким перелётом: панель, шторка, кнопки масштаба, маркер.
- Соседние элементы появляются каскадом с шагом `--dur-stagger`, а не разом: маркеры (A3), блоки панели (до шести шагов, снизу на 6 px), уход интро (текст → подвал → верх).
- Шторка на телефоне выдвигается сдвигом, отпущенная после броска уходит по направлению броска (инерция). Маркер вырастает из точки и подпрыгивает при наведении и фокусе. Подсветка региона под мышью проявляется за 300 мс, гаснет за 200 мс и, пока горит, «дышит» свечением (прозрачность 1 ↔ 0,6, `--hl-breathe-min`), контур ровный.
- Reduced motion: шаг каскада 0, `--ease-spring` = `--ease-out`, сдвиги, масштаб, подпрыгивание и «дыхание» выключены — остаются только кроссфейды.

## 8. Визуальный стиль

### 8.1 Уровни исполнения карты
От лучшего к запасному. Выбираем лучший, который реально сделать:

| Уровень | Описание | Решение |
|---|---|---|
| **A** | Иллюстрированная карта + объёмные ориентиры (3D-модели или 2.5D-спрайты знаковых мест: цитадели, храмы, кристаллы) | Желательно, но может уйти в следующую итерацию |
| **B** | Качественная нарисованная карта с рельефом (как у LoL), детальные картинки регионов для приближения | **Целевой уровень MVP** |
| **C** | Стилизованная пергаментная карта (как фанатская «The Map of the Ancient») | Запасной вариант |

### 8.2 Палитра (фирменный стиль Dota 2)
Тёмный камень и сталь, бронза, красный акцент; Radiant и Dire — смысловые цвета. Точные значения подбираются в дизайн-задаче, ориентиры:

| Токен | Назначение | Ориентир |
|---|---|---|
| `--bg-0` | Фон, виньетка | почти чёрный с холодным оттенком |
| `--bg-1` | Панели | тёмный графит |
| `--metal` | Рамки, разделители | сталь / бронза |
| `--accent` | Акцент, кнопки, фокус | фирменный красный Dota |
| `--radiant` | Подсветка Radiant | зелёный / светлое золото |
| `--dire` | Подсветка Dire | тёмно-красный / огненный |
| `--neutral` | Подсветка нейтральных | холодный серо-голубой |
| `--text-1/2` | Текст | тёплый светлый / приглушённый |

### 8.3 Подсветка регионов
- По стороне: Radiant — зелёный, Dire — красный, нейтральные — нейтральный.
- Если сторона региона в лоре не определена — нейтральный.
- Ярусы: Верхний — светлое свечение, Бездна — огненное.
- Легенда сторон (#102): в мире при ширине ≥ 768 px, левый нижний угол карты — три ромба (Radiant, Dire, Нейтральные земли), мелкий текст `--text-3` без рамки, мышь не ловит; скрыта под интро и при открытом профиле. На телефоне легенды нет — то же объясняют заголовки групп списка регионов.

### 8.4 Типографика
- Заголовки и подписи на карте: засечный шрифт, заглавные, разрядка; на панели — заголовки жирные заглавные.
- Основной текст: читабельный гротеск.
- Фирменные шрифты Valve, скорее всего, использовать нельзя. Берём свободные аналоги с кириллицей (Google Fonts). Выбор — в дизайн-задаче.

### 8.5 Декор
- Срезанные углы у панелей и кнопок (как в интерфейсе Dota 2).
- Тонкие металлические линии с ромбами на концах как разделители.
- Кнопки-ромбы для «закрыть» и «свернуть панель».

### 8.6 Подписи на карте и принятые отступления (аудит E13)
Отчёт — [research/E13-ux-audit.md](research/E13-ux-audit.md). Принято сознательно, в отступление от референса и §5.4, §6.3, §6.6:
- Длинное название региона (> 14 знаков) — в две строки; подпись сдвигается от точки `label` внутрь карты, если иначе вышла бы за край. Подписи ярусов — одной строкой.
- Подпись маркера встаёт сверху, снизу, справа или слева от точки — где не налезает на соседей; если места нет, прячется и появляется при наведении, фокусе и у выбранного места. Столица и выбранное место подписаны всегда.
- Подпись маркера — на тёмной полупрозрачной плашке со скруглением (`--label-plate`), без обводки текста (#98): читается на любом фоне карты, в том числе на будущем арте. Текст подписи (`--text-1…3`) к плашке поверх белого — ≥ 4.5:1. Приглушение при выбранном герое — цветом подписи (`--text-3`), не прозрачностью. Обязательной подписи, которой тесно со всех сторон, достаётся сторона, где она накрывает меньше соседей.
- Под пунктиром нити — тёмная подложка: нить того же цвета, что и подсветка регионов героя, и без подложки теряется.
- Пока летит камера, подсказки региона и места не показываются — они встают у якоря после посадки.
- Облака мира не закрывают подписи (`EDGE_CLOUDS`).
- На нарисованной карте (#112) у названий регионов — мягкая тёмная подложка-свечение (`--map-halo-filter`): на снегу Айсрака контраст подписи к фону под ней ≈ 7:1 (было ≈ 3:1). Подсветка S1h поверх арта — вдвое прозрачнее токенов `--*-glow`; облака, туман и свечение над артом — A7 (#167, токены `--atmo-*`).

Доработки по аудиту (#40):
- Интро: под названием — строка-пояснение «Интерактивная карта мест и героев лора» / «An interactive map of the lore's places and heroes».
- Мир при первом входе: внизу кадра строка «Выберите регион, чтобы узнать о нём больше» / «Pick a region to learn more» (на телефоне — нет, там под картой список регионов, §13). Гаснет после первого наведения, фокуса или нажатия на регион (или если регион уже открыт) и больше не показывается — `localStorage` `dota-lore-map.world-hint`; без `localStorage` покажется снова после перезагрузки. Не видна под интро, при открытом поиске и выбранном герое.
- Галерея с одним медиа — без счётчика «01 / 01».
- Окно «О проекте» — на затемнении `--veil-strong`, как галерея.
- Подписи маркеров не выходят за видимую часть кадра (левее панели, выше шторки): вылезающая подпись ищет другую сторону, иначе прячется до наведения.
- Кадр региона (#112, решено на арте 1:1 и свободной камере): **габарит полигона вписан в свободную часть кадра с полем 12 %** с каждой стороны — одно правило для всех 27 регионов, камеры считает скрипт `map/cameras.mjs`, ручных исключений нет (Айсрак — тоже по правилу). Поле 12 %, а не 8 % из задачи: владелец после #163 просил камеры дальше (#165), 12 % держат то же расстояние для вытянутых регионов и приближают компактные (Глубины, Тропические острова), которые старое правило «0.7 по высоте» держало мелкими. Кадр держит на картинке только видимую часть (без панели и шторки), поэтому регион у края мира (Небеса, Глубины, Кладд) встаёт в свободную часть, а не под панель; под панелью мир может кончиться. Поверх правила кадр не приближает больше 2.5× от «мир целиком» (#179): маленький регион не заполняет экран. Общий кадр по маркерам отклонён (аудит E13): маркеры у всех регионов занимают малую часть габарита.
- Кнопки полосы на телефоне — 44×44 px от 368 px ширины; с кнопкой обратной связи (#73) их 8, и они стоят встык. Уже 368 px (360 px) — 40 px в ширину при высоте 44 px, уже 328 px (320 px) — 38×40 px. До #73 было 7 кнопок и 40×40 px только уже 360 px. Убрать кнопку («О проекте» в меню логотипа) ради 44 px на 320 px отказались: экраны 320 px редки, а 40 px выше WCAG 2.5.8 AA (24 px).

## 9. Создание карты (ассеты)

1. **Исследование:** собрать все места из лора (эпик E1) и фанатские карты как референс:
   - [пост ВКонтакте с подборкой фанатских карт](https://vk.ru/wall-115027503_243167);

2. **Схема расположения:** наброс-схема (блоками), где какой регион, кто с кем граничит, где море и острова, где ярусы. Согласуется с владельцем продукта до генерации.
3. **Генерация:** изображение мира по схеме (нейросеть + ручная доработка). Требования:
   - **на картинке нет текста** — все подписи накладываются в HTML (для RU/EN);
   - мир — не меньше 4096 px по ширине; для каждого региона — отдельная детальная картинка (≥ 2560 px) в той же стилистике;
   - в каждом регионе есть место под подписи и маркеры;
   - узнаваемая среда региона (лёд, пустыня, лес, лава);
   - **стиль** (решение владельца 2026-11-18): реалистичный рельеф, как с орбиты; города — в масштабе карты; лун на картинке нет — Безумная Луна и Луна Селемены будут отдельным слоем (уровень A).
   Картинка мира готова (#163): исходник — `map/art/world.jpg` (5016×5016), основа генерации — `map/art/base/`.
4. **Разметка:** полигоны регионов (SVG-пути) и координаты локаций в единой системе координат (нормированные 0..1 относительно картинки мира).
5. **Оптимизация:** WebP/AVIF, превью низкого разрешения для интро. Мир — `public/art/world-4096.webp` и превью `world-1024.webp` (его ждёт кнопка «Начать»).

2. Комиксы Valve, страницы арканы/персон, официальные синематики и трейлеры (YouTube-канал Dota 2).
3. «DOTA: Dragon's Blood» (Netflix): **только кадры как медиа**; места и факты из сериала на карту не добавляем (решение В5).
4. Liquipedia, Dota 2 Wiki (Fandom) — для сверки и поиска мест.

### 11.2 Правила
- Лор региона и локаций — пересказ своими словами, не копирование текста источников.
- Медиа — только официальные арты и синематики, **только лучшее**, ≤ 3 на место. Видео встраиваются с YouTube, не перезаливаются.
- Нет контента — нет блока. Заглушки не показываем.
- У каждого региона хранится список источников (`sources`).

### 11.3 Портреты героев
Берутся с CDN Valve: копируем в репозиторий или ссылаемся напрямую (решается при реализации).

## 12. Локализация
- RU и EN, переключатель в левой панели и на интро.
- Язык по умолчанию — из языка браузера (`ru*` → RU, иначе EN), выбор сохраняется в `localStorage`.
- Имена героев — официальные в каждой локализации. В русском клиенте Dota 2 официальные имена героев — латиницей (Pudge, Crystal Maiden), поэтому имя одно на оба языка; русские написания и прозвища (Пудж, ЦМ) — алиасы для поиска (§6.5, ARCHITECTURE A3).
- Тексты интерфейса — в отдельном файле словаря.
- Переключение языка — без перезагрузки и без потери экрана: адрес, выбранный герой, открытая галерея и панель остаются; меняются тексты, `<html lang>`, заголовок вкладки, картинки комиксов и язык ссылок на dota2.com.

## 13. Адаптивность

| Ширина | Поведение |
|---|---|
| ≥ 1280 | Основной макет: левая панель, карта, правая панель |
| 768–1279 | Правая панель уже, может перекрывать карту; сворачивается |
| < 768 | Правая панель → **нижняя шторка** (открывается свёрнутой, снова сворачивается при переходе к другому месту; камера кадрирует часть карты над ней) (свёрнута ~30 % высоты, развёрнута ~90 %, жест «потянуть»); левая панель → компактная верхняя или нижняя полоса; наведения нет: тап по региону сразу открывает его; галерея на весь экран, свайп для листания; в мире (S1) карта прижата к верху, под ней — **список регионов** (см. ниже) |

**Мир на телефоне — список регионов под картой** (решение владельца 2026-11-12, #39; вариант 1 из аудита E13). На 375 px карта мира — 375×234 px, подписи ≈ 7 px, мелкие регионы — цели 30–40 px. Поэтому на ширине < 768 px в мире:
- карта целиком (§5.3 не меняется: камера статична, без перетаскивания и зума) прижата к верху кадра и по-прежнему нажимается; пустое место под ней занимает прокручиваемый список всех регионов. Телефон боком (карта во всю высоту) — карта слева, список справа;
- группы — сверху вниз, как на карте: Верхний ярус, Radiant, Нейтральные земли, Dire, Бездна; внутри группы — по алфавиту языка интерфейса (английский артикль «The» не учитывается);
- пункт — кнопка ≥ 44 px: ромб цвета стороны или яруса (§8.3), название на языке интерфейса, число героев («7 героев» / «7 heroes»);
- нажатие на пункт — то же, что тап по региону на карте (тот же адрес, перелёт камеры, шторка); в регионе и месте списка нет. Наведение мышью и фокус с клавиатуры подсвечивают регион на карте (без подсказки). Вернулись в мир (Esc, крошка, глобус) — фокус на тот же пункт списка, если регион открыли из него (§14: фокус возвращается туда, откуда пришли);
- выбран герой (§6.5): его регионы в списке отмечены цветом, остальные приглушены, но нажимаются; профиль героя — в шторке поверх списка, без профиля карта со списком встаёт под чип героя (§6.8);
- строка-подсказка мира (§8.6) на телефоне не показывается: её роль играет список с заголовком «Регионы».
На ширине ≥ 768 px мир не меняется — подписи там 13–23 px.

## 14. Нефункциональные требования
- **Производительность:** интро отображается < 2 с на хорошем соединении; первая загрузка до старта мира ≤ ~3 МБ; детальные картинки регионов подгружаются заранее при наведении на регион; анимации камеры и частицы — 60 FPS на среднем ноутбуке.
- **Доступность:** навигация с клавиатуры (Tab по регионам и локациям, Enter — открыть, Esc — назад/закрыть), видимый фокус, `alt` у изображений, `prefers-reduced-motion`, контраст текста не ниже WCAG AA.
- **Браузеры:** две последние версии Chrome, Edge, Firefox, Safari; Яндекс Браузер.
- **Хостинг:** статический сайт без бэкенда. Приоритет — GitHub Pages, запасные варианты — Vercel или свой сервер.

- Дисклеймер в окне «О проекте» (RU и EN) и в подвале интро (одной строкой на языке интерфейса, #187): некоммерческий фанатский проект, не связан с Valve Corporation и не одобрен ею; Dota 2 и связанные материалы — товарные знаки и собственность Valve.
