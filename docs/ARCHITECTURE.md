# Архитектура

Решения, обязательные для всех, кто пишет код. Функциональные требования — в [SPEC.md](SPEC.md). Изменить решение можно только правкой этого файла в отдельном PR с объяснением.

## A1. Стек

| Что | Решение |
|---|---|
| Сборка | Vite, статический сайт без бэкенда |
| UI | React 18 + TypeScript (`strict: true`), без UI-библиотек |
| Стили | CSS Modules + CSS custom properties (токены из дизайн-системы, `src/styles/tokens.css`) |
| Состояние | React context + `useReducer` для навигации; без Redux/Zustand |
| Анимации | CSS transitions / Web Animations API; без анимационных библиотек |
| Частицы | `<canvas>` поверх карты, свой небольшой движок |
| Тесты | Vitest + @testing-library/react (jsdom) |
| Линт | ESLint (typescript-eslint, react-hooks) |
| Node | 22 LTS, npm |

## A2. Структура репозитория

```
research/e1/        исследование лора: heroes.json, regions.json, hero-places.json, build.py (источник правды о регионах, местах и героях)
content/            тексты: content/regions/<regionId>.json (RU/EN описания, характеристики, тексты мест); content/media.json (медиа галереи)
map/                геометрия карты: map/layout.json (полигоны, позиции, камеры), арт в map/art/
scripts/            build-data.mjs — собирает research + content + map в src/data/world.generated.json
src/
  app/              корень приложения, роутинг, провайдеры
  features/         экраны и крупные блоки: intro, world, region, location, gallery, search, panel (правая панель), rail (левая панель §6.1)
  components/       переиспользуемые компоненты дизайн-системы
  data/             типы данных, загрузка, world.generated.json (генерируется, коммитится)
  i18n/             словарь интерфейса ru.json / en.json, хук useT(): t(key) — строки интерфейса, l({ ru, en }) — контент

```

## A3. Данные

- **Источник правды** — JSON в `research/e1/`, `content/`, `map/`. Приложение их напрямую не читает.
- `npm run data` (`scripts/build-data.mjs`) сливает их в **один** файл `src/data/world.generated.json` и валидирует. Файл коммитится, чтобы сборка не зависела от скриптов.
- Отсутствующий контент (нет описания, нет позиции на карте) — не ошибка: приложение просто не показывает блок или маркер. Ошибка — ссылка на несуществующий регион, место или героя.
- Каждый текст `{ ru, en }` — оба языка непустые, в `en` нет кириллицы (иначе это забытый перевод) — ошибка `build-data.mjs`. Словари `src/i18n/*.json`: одинаковые ключи и переменные `{…}`, в `en.json` нет кириллицы — проверяет `i18n.test.ts`.
- Тексты — объекты `{ "ru": "...", "en": "..." }`. Тип в TS: `Localized`.
- В русских текстах названия героев пишутся латиницей, точно как в `research/e1/heroes.json` (как в русском клиенте игры); личные имена персонажей — кириллицей.

### Формат `content/regions/<regionId>.json`
```jsonc
{
  "id": "icewrack",
  "subtitle": { "ru": "...", "en": "..." },
  "biome": "snow",               // snow | forest | jungle | desert | mountains | plains | swamp | sea | islands | volcanic | city | sky | void | hell | fog
  "ambient": { "type": "snow", "density": 0.6 },   // snow | ash | embers | fog | rain | sparkles | stars | leaves | sand | none
  "traits": {
    "rule":  { "ru": "...", "en": "..." },
    "magic": { "ru": "...", "en": "..." },
    "biome": { "ru": "...", "en": "..." }
  },
  "description": { "ru": "...", "en": "..." },
  "media": ["icewrack-new-neighbors"],   // необязательно: id из content/media.json, ≤ 3
  "places": {
    "<Place name из research/e1/regions.json>": {
      "name": { "ru": "...", "en": "..." },
      "type": { "ru": "...", "en": "..." },
      "description": { "ru": "...", "en": "..." },
      "media": ["frostreach-the-dragon"]   // необязательно, ≤ 3
    }
  }
}
```
Сторона (`side`) и название региона берутся из `research/e1/regions.json`.

Необязательное поле `"moreLink": "https://…"` — ссылка «Подробнее ↗» в панели региона (SPEC §5.4 п. 6); только `https://`. Медиа (`media` у региона и места — список id из `content/media.json`) и шапка места (`art`) панель показывает, если они есть. Клик по карточке медиа ставит `?media=<id>` (A5).

### Формат `content/media.json`
Медиа галереи (SPEC §5.6, §10) — один файл на весь мир; регион и место ссылаются на медиа по `id` (поле `media` выше), поэтому одно медиа можно показать в нескольких местах.
```jsonc
{
  "note": "...",
  "media": [
    {
      "id": "frostreach-the-dragon",          // kebab-case, уникален
      "type": "image",                        // image | youtube
      "src": "https://cdn.steamstatic.com/...",   // только у image: https-ссылка или относительный путь к ассету;
                                              // или { "ru": "...", "en": "..." }, если у картинки есть версии на двух языках
      "youtubeId": "xxxxxxxxxxx",             // только у youtube: 11 символов, встраивание через youtube-nocookie.com
      "excerpt": true,                        // необязательно, только у image: картинка — одна страница комикса,
                                              // целиком он по sourceUrl (метка «отрывок», кнопка «Читать комикс целиком ↗»)
      "title":       { "ru": "...", "en": "..." },
      "subtitle":    { "ru": "Комикс", "en": "Comic" },   // тип: Комикс | Синематик | Арт | Трейлер
      "description": { "ru": "...", "en": "..." },         // необязательно
      "credit": "Valve Corporation",          // правообладатель (SPEC §15)
      "sourceUrl": "https://www.dota2.com/..."   // страница источника, https
    }
  ]
}
```
- Только официальные материалы Valve (SPEC §11.2): комиксы и страницы dota2.com, синематики и трейлеры с YouTube-канала Dota 2, официальный арт. Каждая ссылка проверяется вручную перед добавлением; сомнительное не добавляем. Тексты — свои слова.
- Страницы комиксов с текстом даём на языке интерфейса: `src: { ru, en }` (проверено, что русская страница на CDN есть и отличается от английской); нет русской версии — `src` строкой, показывается английская. Выбор — `mediaSrc(m, lang)` в `src/data/world.ts`.
- Картинки в репозиторий не копируем: `src` — прямая ссылка на CDN Valve (как портреты в A6). Нет прямой официальной ссылки — медиа не добавляем.
- Комикс в галерее — одна страница плюс явная ссылка на весь комикс (решение владельца 2026-11-11, #7): у таких медиа `"excerpt": true`. Страница — не обязательно первая (берётся самая показательная), поэтому метка — «отрывок», а не «страница 1 из N».
- Ссылка на источник открывается на языке интерфейса: у `www.dota2.com` к `sourceUrl` добавляется `l=russian|english` (`mediaSourceUrl(m, lang)`, как у страниц героев в A6); остальные источники — как есть.
- Ошибка: неизвестный `id` в ссылке, больше 3 медиа у региона или места, повтор id, нет ни `src`, ни `youtubeId`, `src` у видео или `youtubeId` у картинки, `excerpt` не `true` или не у картинки, `http://` в `src`/`sourceUrl`, нет `credit`, неполный перевод. Предупреждение: медиа ни к чему не привязано.
- В `world.generated.json`: `World.media` (все медиа), `Region.media` и `Place.media` — списки id. Нет медиа — поля нет.

### Формат `research/e1/hero-aliases.json`
Алиасы для поиска героя (SPEC §6.5) — отдельно от `heroes.json`, потому что тот повторяет официальный список Valve, а алиасы — наши словарные данные.
```jsonc
{ "note": "...", "aliases": { "<hero key>": ["Пудж", "Butcher", "Мясник"] } }
```
- Что кладём: кириллическое написание имени, общеизвестные сокращения и прозвища сообщества (`CM`, `КМ`, `Войд`), личные имена персонажей (`Rylai`, `Райлай`). Сомнительное не добавляем.
- Сравнение без учёта регистра, `ё`/`е` и лишних пробелов (`normalizeAlias` в `scripts/build-data.mjs`); поиск в приложении нормализует так же.
- Ошибка: неизвестный ключ героя, пустая строка, повтор внутри героя, совпадение с именем героя. Предупреждение: один алиас у нескольких героев. Проверяют и `build-data.mjs`, и `build.py`.
- В `world.generated.json` — поле `Hero.aliases` (нет алиасов — поля нет).

### Формат `map/layout.json`
Координаты нормированы: `x, y ∈ [0, 1]` относительно картинки мира с соотношением сторон **16:10** (`aspect: 1.6`).
```jsonc
{
  "aspect": 1.6,
  "bands": { "upper": [0, 0.13], "abyss": [0.87, 1] },   // полосы ярусов по y
  "regions": {
    "<regionId>": {
      "polygon": [[x, y], ...],          // замкнутый контур, без самопересечений
      "label": [x, y],                   // якорь названия и подсказки
      "camera": { "x": 0.2, "y": 0.3, "zoom": 3 }   // центр кадра и масштаб при приближении
    }
  },
  "places": { "<Place name>": { "pos": [x, y] } }
}
```
- `camera.zoom = z`: кадр 16:10 показывает `1/z` ширины и высоты мира; центр уже ограничен так, чтобы кадр не выходил за картинку.
- Соседние регионы на суше делят границу (общие вершины), полигоны не пересекаются; места — внутри полигона своего региона, между местами одного региона ≥ 0.012. Проверка — `node map/check-layout.mjs`, схема — `node map/render-schema.mjs` → `docs/map/schema.svg` (подробности — [map/README.md](map/README.md)).

## A4. Карта и камера

- Один слой карты `MapStage`: картинка мира (или процедурная заглушка, пока нет арта) + SVG-оверлей в той же системе координат (`viewBox="0 0 1600 1000"`, нормированные координаты × 1600/1000).
- Камера — CSS `transform: translate() scale()` на слое карты, анимация через Web Animations API. Длительности — из SPEC §7.1.
- Заглушка арта: полигоны регионов, залитые цветом биома, с текстурой через SVG-фильтр `feTurbulence`. Позволяет делать всё приложение до готовности арта (E2).
- Слои SVG сверху вниз: подписи (`aria-hidden`) → заливка подсветки S1h (`aria-hidden`, без событий мыши) → полигоны-кнопки. Подсветка лежит над всеми полигонами, чтобы светлая граница не пряталась под соседями. Подсветка, подписи ярусов и подсказка — только в мире (S1); в S2/S3 их нет.
- Наведение = фокус с клавиатуры: оба показывают подсветку и подсказку. Наведение пальцем (`pointerType === 'touch'`) игнорируется — на тач-устройствах подсказки нет, тап сразу открывает регион (SPEC §5.3).
- Подсказка региона (`RegionTooltip`) рендерится порталом в `document.body` с `position: fixed`: у слоя карты есть `transform`, а у экрана мира под интро — `filter`, и оба ломают `fixed` у потомков. Позиция — у якоря `label` региона, с прижатием к краю окна (`placeTooltip`).

### Регион и место (S2/S3)
- Правая панель лежит **поверх** карты (`position: absolute` у правого края), а не рядом с ней: свернуть и развернуть её можно без смещения карты (SPEC §5.4). Ширина — токен `--panel-width`, сколько кадра она закрывает — `--panel-inset` (в px, его читает JS; на узком экране `0px`).
- Камера региона и места кадрирует свободную часть кадра слева от панели: `frameCamera` уменьшает `zoom` из `layout.camera` в (ширина кадра − панель) / ширина слоя раз, сдвигает центр к краю мира, чтобы за картинкой было меньше пустоты, и даёт сдвиг `offset = inset / 2` (px) для `cameraTransform`. Без измерений (jsdom) камера та же, что в `layout.json`.
- Панель кадр учитывает всегда, свёрнута она или нет, — поэтому сворачивание камеру не трогает. Свёрнутая панель раскрывается сама при смене региона или места.
- В S2/S3 полигоны регионов — не кнопки: соседи затемнены (`filter`) и не ловят мышь, активный регион — «пустое место» карты; клик по нему в S3 возвращает в S2 (SPEC §5.1).
- Маркеры мест рисуются в группе `translate(pos) scale(k)`, где `k` переводит единицы SVG в экранные пиксели (`1600 / ширина слоя / zoom`): размер маркеров и подписей не зависит от приближения и окна.
- A3: названия регионов гаснут в первой трети перелёта и возвращаются в последней, маркеры появляются в последней трети с шагом 40 мс, панель выезжает за `--dur-panel`. A4: содержимое панели — fade `--dur-fade` по смене ключа. Длительности камеры — токены `--dur-camera` (мир ↔ регион) и `--dur-place` (внутри региона).
- При `prefers-reduced-motion` камера не едет: кадр гаснет и проявляется на новом месте за `--dur-camera`/`--dur-place` (200 мс).

### Клики во время анимации камеры
SPEC §7.1: анимация камеры не прерывается кликами. `MapStage` на время анимации «занимает» навигацию (`hold()` из `app/navigation.tsx`); все переходы через `open()` — глобус, крошки, Esc, маркеры, регионы — в это время не выполняются, а запоминаются, и после посадки выполняется **последний** запрошенный. Переход извне (кнопка «назад» браузера, ручной адрес) очередь сбрасывает и применяется сразу: камера продолжает с текущего положения (`getComputedStyle(...).transform`).

### Интро поверх мира
Экран мира рендерится всегда, в том числе на `#/`. Интро (S0) — слой `position: fixed` над ним; экран мира под интро получает `veiled`: размытие `--map-blur`, `scale: 1.08`, `inert` и `aria-hidden`. Так «размытая карта на фоне» — это настоящая карта, и A1 проявляет её без подмены картинки: по «Начать» адрес сразу меняется на `#/world`, с карты снимаются размытие и масштаб (CSS-переход), а интро ещё `--dur-intro` остаётся поверх, пока облака разъезжаются и текст уходит вверх. Длительности JS берёт из токенов (`cssDuration`), поэтому `prefers-reduced-motion` действует и на них.

Кнопка «Начать» включается, когда готовы шрифты дизайн-системы (`document.fonts`) и картинка мира (`WORLD_ART`), но не позже чем через 4 с — медленная сеть не запирает на интро (`features/intro/useWorldReady.ts`).

## A5. Навигация и адреса

Решение по В2 (SPEC §17): **да**, у каждого состояния свой адрес, через hash — работает на GitHub Pages без серверных правил.

| Экран | Адрес |
|---|---|
| Интро | `#/` |
| Мир | `#/world` |
| Регион | `#/r/<regionId>` |
| Место | `#/r/<regionId>/<placeSlug>` |
| Выбранный герой | `?hero=<heroKey>` поверх любого адреса |
| Галерея | `?media=<mediaId>` поверх адреса региона/места |

`placeSlug` — имя места в kebab-case (`"Tomo'kan"` → `tomokan`).

Галерея (`features/gallery/`): листает медиа экрана, с которого открыта (места или региона); `?media=` с чужим медиа (адрес вручную) показывает его одно, неизвестный id или интро — галереи нет. Открытие карточкой — новая запись в истории; листание и закрытие меняют адрес без новой записи (`navigate(route, { replace: true })`), поэтому «назад» браузера закрывает галерею и не перебирает страницы.

## A6. Герои

- Ключ героя — `key` из `research/e1/heroes.json` (`antimage`, `crystal_maiden`).
- Портреты — решение по В7: **ссылаемся на CDN Valve** (`https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/heroes/<key>.png`), с запасной заглушкой при ошибке загрузки. Не копируем в репозиторий.
- Ссылка на страницу героя: `https://www.dota2.com/hero/<slug>?l=<russian|english>`, где `slug` — английское имя в нижнем регистре без пробелов и знаков.

## A7. Деплой и проверки

- GitHub Actions: на каждый PR — `npm ci && npm run check`; на push в `main` — сборка и деплой на GitHub Pages (`base: '/dota-lore-map/'`).
- `npm run check` = `data` (сборка и валидация данных) + `typecheck` + `lint` + `test` + `build` + `scripts/check-budget.mjs` (бюджет загрузки, A14) + `map/check-layout.mjs` + `python research/e1/build.py --check`.
- Ничего не мержится с красным CI.

## A8. Дизайн-система

- Токены (SPEC §8.2) — только в `src/styles/tokens.css` на `:root`; компоненты берут значения через `var(--…)`, цвета в коде не пишем. Исключение — заливка биомов процедурной заглушки карты (`features/world/biomes.ts`), её заменит нарисованная карта E2/E4.
- База (фон, типографика, фокус-кольцо `--accent-bright`, скроллбары, `prefers-reduced-motion`) — `src/styles/global.css`. При reduced motion токены длительностей переопределяются: переходы камеры и интро — 200 мс, наведение и панель — мгновенно.
- Шрифты (решение В6) — Google Fonts через `<link>` в `index.html`, `display=swap`, с запасными системными:
  - `--font-display`: **Cormorant SC** — засечки с острыми клиновидными концами и настоящие капители с полной кириллицей ближе всех свободных шрифтов к заголовкам Valve (Trajan-подобным).
  - `--font-body`: **Manrope** — гротеск с кириллицей, хорошо читается мелким кеглем на тёмном фоне.
- Компоненты интерфейса — `src/components/` (CSS Modules): `Button` (primary/ghost, срезанные углы `clip-path`), `DiamondButton` (закрыть/свернуть/назад/листать), `Divider` (линия с ромбами), `HeroPortrait` (портрет по A6, заглушка при ошибке), `PanelFrame` (рамка правой панели), `Tooltip`. Блоки правой панели — `features/panel/`: `Panel` (док с кнопкой-ромбом «свернуть», выезд и кроссфейд), `Breadcrumbs` (SPEC §6.4), `Traits` (2×2, SPEC §4.2), `MediaCards` (до 3 карточек); `HeroList` с `max` прячет остальных героев за кнопкой «+N».
- Подсветка регионов на карте — цвет стороны с прозрачностью (`--radiant-glow`, `--dire-glow`, `--neutral-glow`), SPEC §8.3. Регионы ярусов подсвечиваются не по стороне, а своим свечением: Верхний — `--upper`/`--upper-glow`, Бездна — `--abyss`/`--abyss-glow`; их подписи светятся всегда (SPEC §6.3).
- Иконки — `components/Icon.tsx`, inline SVG с `currentColor`. Кнопки-иконки без текста получают имя из подсказки (`Tooltip mode="label"`, `aria-labelledby`).
- Окна поверх интерфейса («О проекте», галерея) рендерятся порталом в `document.body`, Esc в окне закрывает только окно, фокус уходит внутрь, Tab не выходит из окна (`components/focusTrap.ts`) и после закрытия возвращается на кнопку-источник. «О проекте» гасит Esc через `stopPropagation`; галерея слушает Esc и ← / → на `window` (фокус может оказаться на `body`), а глобальный Esc «на уровень вверх» при открытой галерее молчит.

## A9. Облака

- Облако — `<span>` с несколькими `radial-gradient` цвета `--cloud`/`--cloud-shade` и `filter: blur`; картинок нет. Наборы облаков — данные в `features/world/cloudSets.ts`: центр `x, y` и ширина `w` в процентах контейнера, слой `1 | 2 | 3` (1 — дальний: мельче, бледнее, медленнее; 3 — ближний).
- Компонент `Clouds` в двух режимах: `veil` — пелена интро (`VEIL_CLOUDS`), при A1 каждое облако уходит от центра экрана к своему краю (`partOffset`, в vw/vh) и тает; `drift` — облака по краям мира (`EDGE_CLOUDS`), A7: CSS-анимация дрейфа, у слоёв разные амплитуда и период (48–84 с) — это и есть параллакс. В регионе (S2/S3) облака мира скрыты.
- При `prefers-reduced-motion` дрейф выключен, а A1 — только растворение без сдвига.
- Когда появится нарисованная карта, облака остаются CSS-слоем поверх неё; меняются только цвета токенов и, при желании, наборы в `cloudSets.ts`.

## A10. Арт карты и предзагрузка

- Адреса арта: картинка мира — `WORLD_ART`, детальная картинка региона — поле `layout.art` региона (в `map/layout.json` → `world.generated.json`). Обе — в `features/world/art.ts`; пока арта нет, они пустые, и всё ниже безопасно ничего не делает.
- Детальная картинка региона — SVG `<image>` под маркерами, покрывает рамку `layout.camera` (1/zoom мира вокруг центра) и проявляется кроссфейдом (`--dur-fade` после `--dur-camera`), когда загружена (`features/world/RegionArt.tsx`). Нет арта — ничего не рисуется.
- `preloadImage(url)` грузит картинку через `new Image()` один раз на адрес и никогда не отклоняется (ошибка = «готово»). `preloadRegionArt(region)` вызывается при наведении и фокусе на регион (SPEC §14), картинка мира ждётся кнопкой «Начать».
- Чтобы подключить арт: положить файлы в `public/` (или импортировать через Vite), заполнить `WORLD_ART` и `layout.art` с учётом `import.meta.env.BASE_URL`; `scripts/build-data.mjs` должен пропускать поле `art` и проверять, что файл есть.

## A11. Поиск героя и нити

- Код — `features/search/`: `search.ts` (поиск, места героя, куда вести камеру), `HeroSearch` (поле с автодополнением, ARIA combobox), `HeroBadge` (плашка), `preview.tsx` (контекст «чей портрет под курсором»). Геометрия нитей — `features/world/threadGeometry.ts`, отрисовка — `features/world/Threads.tsx` внутри SVG карты.
- Поиск: сравнение без регистра, «ё» и знаков (`normalize`) по английскому имени, ключу (`anti_mage` → «anti mage») и алиасам `research/e1/hero-aliases.json`. Порядок: точное совпадение, начало строки, начало слова (и строка без пробелов), вхождение; при равенстве — по имени; не больше 8 вариантов. Нашли по алиасу — алиас показывается рядом с именем.
- Выбранный герой — только `?hero=<key>` в адресе (A5): переход на другой экран его сохраняет (`open`), × и Esc снимают. Порядок Esc: галерея → поле поиска → выбранный герой → уровень вверх.
- Места героя (`heroSpots`) — его связи по порядку из `research/e1/hero-places.json`, без повторов. Связь с регионом целиком — точка подписи региона (`layout.label`). Камера при выборе (`heroScreen`): одно место — S3 (или S2 для региона целиком), все места в одном регионе — S2, иначе мир.
- Приглушение: в мире регионы без мест героя затемнены (`muted`), его регионы подсвечены как при наведении; в S2/S3 маркеры его мест светятся (`heroSpot`), остальные приглушены. Нити рисуются при выбранном герое и при наведении или фокусе на портрет в панели, если у героя ≥ 2 мест; наведение важнее выбора и живёт до смены экрана.
- Нить — квадратичная дуга между соседними местами (контрольная точка сдвинута перпендикулярно хорде на 0.22 её длины, всегда вверх), цвет — тон первого места (сторона или ярус). Толщина и пунктир в экранных px при любом приближении. A5: прорисовка — `stroke-dashoffset` от длины дуги к 0 за `--dur-thread`, затем бесконечное течение пунктира; на концах — вспышка.
- Нить за краем кадра (S2/S3): точки мира переводятся в px кадра той же формулой, что и `cameraTransform` (`toScreen`), по дуге от видимого конца ищется последняя точка внутри видимой части (слева от панели, отступ 28 px) — там кнопка со стрелкой по направлению дуги и названием места; клик ведёт к нему. Пока кадр не измерен (jsdom), меток нет.

## A12. Атмосфера и звук

- Частицы (SPEC §7.3) — `features/atmosphere/`: `particles.ts` — чистая симуляция (параметры видов `SPECS`, `particleCount`, `spawn`, `step`, `twinkle`), `AmbientCanvas` — один `<canvas>` поверх кадра карты в S2/S3 (в мире его нет), тип и плотность — `ambient` региона. Число частиц ∝ плотности и площади кадра (эталон 1280×800), потолок `MAX_PARTICLES` = 220; рисуются только примитивы (круг, линия, эллипс, прямоугольник), туман — заранее нарисованный спрайт с градиентом, свечение углей — ореол вместо `shadowBlur`. `devicePixelRatio` ≤ 2. Цикл — `requestAnimationFrame`, на скрытой вкладке стоит, шаг ≤ 50 мс. Цвета — токены `--particle-*` в `tokens.css`. При `prefers-reduced-motion` канвас не создаётся.
- Звуки (SPEC §7.4) — синтез Web Audio (`src/app/sfx.ts`): наведение (короткий тихий тон), клик, открытие панели (шорох фильтрованного шума и низкий тон), открытие галереи (два тона). Файлов нет — нечего лицензировать и загружать; записанные звуки, если появятся, подключаются заменой `createSynth`.
- `SoundProvider` (`src/app/sound.tsx`) решает, играть ли: звук включён (`localStorage`) и разблокирован. Разблокирует «Начать» или первый жест на любом экране (по прямой ссылке «Начать» нет); `AudioContext` создаётся только внутри этого жеста. «Клик» — один слушатель на `document` для `button`, `a[href]`, `[role=button]`, `[role=option]`; наведение на регион и маркер — `useSfx()` в `MapStage`, не чаще раза в 90 мс; открытие панели — при появлении региона на экране, галереи — при её открытии. Без провайдера `useSfx()` молчит.

## A13. Адаптив

- Ширины (SPEC §13) — медиазапросы в CSS и `MOBILE_QUERY` (`(max-width: 767px)`, `features/world/camera.ts`) в JS; `useMediaQuery` (`src/app/media.ts`) следит за поворотом и ресайзом.
- ≥ 1280 — основной макет. 768–1279 — панель уже (`--panel-width: 380px`, `--panel-inset: 412px`), по-прежнему поверх карты и сворачивается ромбом.
- < 768 — левая панель — полоса сверху (`--rail-height`), экран — `100dvh`. Правая панель — нижняя шторка `features/panel/Sheet.tsx`: свёрнута `SHEET_PEEK` = 30 % высоты окна, развёрнута `SHEET_FULL` = 90 %; ручка на всю ширину — тап переключает, «потянуть» (pointer events, `touch-action: none`) меняет высоту, отпустили — встаёт в ближайшее положение; новый регион или место — снова свёрнута. Свёрнутость дока на компьютере к шторке не относится.
- Камера знает о шторке: `View.insetBottom` = 30 % высоты окна, `frameCamera` уменьшает zoom, если рамка региона выше свободной части, и поднимает центр на половину шторки (`offsetY` в `cameraTransform`); метки «нить за краем» считают видимой часть над шторкой.
- Тач: подсказки региона и места открываются только мышью и фокусом (`pointerType !== 'touch'`), тап сразу открывает регион или место; галерея на весь экран и листается свайпом (A5, E6).

## A14. Качество: доступность, производительность, браузеры

SPEC §14, эпик E11.

**Клавиатура.** В мире Tab идёт по полигонам регионов (`role="button"`, `tabindex="0"`, порядок — порядок в `layout.json`), в регионе и месте — по маркерам мест, затем по панели. Enter и пробел открывают, Esc — на уровень вверх (A11 — порядок Esc). Фокус с клавиатуры показывает ту же подсветку и подсказку, что и наведение (A4).
- Фокус не теряется при переходе (`features/world/focus.ts`, вызывается из `WorldScreen` при смене экрана). Если элемент с фокусом пропал, скрыт или перестал быть фокусируемым (полигон в S2 — уже не кнопка, крошки уехали с панелью), фокус ставится: вверх (место → регион, регион → мир) — на маркер места или полигон региона, откуда пришли; вниз и вбок — на заголовок панели (`h2` с `tabindex="-1"` и `data-panel-heading`, без кольца — `[tabindex='-1']:focus` в `global.css`). Фокус, который пользователь держит, не трогаем; `focus({ preventScroll: true })`.
- Окна (галерея, «О проекте») — A8: ловушка фокуса, возврат на кнопку-источник.

**Контраст (WCAG AA).** Цвета текста — `--text-1…3`, `--metal-bright`, `--neutral`, `--radiant` — ≥ 4.5:1 на `--bg-0…2`; кольцо фокуса `--accent-bright` ≥ 3:1 (WCAG 1.4.11). Красный `--accent` и тёмный металл — только рамки и заливки, не текст (на `--bg-2` у `--accent` 2.9:1); выбранный язык — светлый текст на `--accent-dim`. Имя ссылки или кнопки с видимым текстом начинается с этого текста (WCAG 2.5.3: «dota2.com: …», «+N: …»). Проверяет `src/styles/quality.test.ts` по `tokens.css` и CSS-модулям.

**Картинки.** У каждого `<img>` есть `alt`: портрет-ссылка — `alt=""` (имя у ссылки), портрет без ссылки — имя героя, картинка галереи — название медиа, шапка места — `alt=""` (декор). Проверяет `quality.test.ts`.

**prefers-reduced-motion.** Токены длительностей укорачиваются в `global.css` (A8). Кроме того, каждый CSS-файл с движением — бесконечной анимацией или ключевыми кадрами со сдвигом/масштабом — сам выключает его в `@media (prefers-reduced-motion: reduce)`: панель и шторка появляются без выезда, нить нарисована сразу и не течёт, подсказка и плашка героя без сдвига, медиа галереи без увеличения, карта под интро без масштаба, облака без дрейфа, спиннер без вращения; камера — кроссфейд (A4), частиц нет (A12). Новый файл с движением без такого блока роняет `quality.test.ts`.

**Бюджет загрузки.** До мира грузятся `index.html`, бандл JS и CSS (данные мира внутри бандла) и шрифты Google Fonts; портреты и медиа с CDN Valve — только в мире (панели, подсказки, галерея; портреты `loading="lazy"`). `scripts/check-budget.mjs` (часть `npm run check`) считает gzip html/js/css из `dist` и падает, если бандл > 600 КБ или вместе с оценкой шрифтов (400 КБ) > 3 МБ. Картинка галереи грузится без `lazy` (она видна сразу и обычно — самый крупный элемент) и занимает всю ячейку (`object-fit: contain`), чтобы кадр не прыгал при загрузке.

**Замеры.** Lighthouse (desktop) — `npx lighthouse <url> --preset=desktop` по `npm run preview`: интро, мир, регион, место, галерея, выбранный герой. Цифры последнего замера — в PROJECT_STATE.
