Эпики E3–E13, E15–E16 закрыты; E17 — осталась #75.
- **Данные:** 26 регионов, 172 места, 127 героев, 409 алиасов, тексты RU/EN у всех регионов и мест, 7 комиксов в галерее. Схема мира `map/layout.json` согласована 2026-11-11.
- **E14 (сверка лора):** партии 01–04 слиты (40 героев из 127). Счётчики: связей 176, без уточнения типа (`link`) — 27, путей 2, связей героев 52, профилей 40, кандидатов в места 9.

- **Проверки:** `npm run check` — 315 тестов vitest + 18 Python, бандл 192 КБ gzip (бюджет 600). e2e и других движков нет (#105). Коммиты и версии — стандарт habze (A7): squash, заголовок PR по Conventional Commits, версии ведёт release-please.
