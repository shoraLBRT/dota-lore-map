Эпики E3–E13, E15–E16 закрыты; E17 — осталась #75.
- **Данные:** 26 регионов, 172 места, 127 героев, 409 алиасов, тексты RU/EN у всех регионов и мест, 20 медиа в галерее (7 комиксов, 4 трейлера, 3 арта событий, 6 карточек Artifact; медиа у 10 регионов из 26 — [research/E1-media-sources.md](research/E1-media-sources.md)). Схема мира `map/layout.json` согласована 2026-11-11.
- **E14 (сверка лора):** партии 01–04 слиты (40 героев из 127). Счётчики: связей 176, без уточнения типа (`link`) — 27, путей 2, связей героев 52, профилей 40, кандидатов в места 9.
- **Карты нет:** вместо арта — процедурная заглушка (плоские полигоны по биомам).
- **Проверки:** `npm run check` — 378 тестов vitest + 18 Python, бандл 202 КБ gzip + шрифты 100 КБ (бюджет 600 и 3 МБ). `npm run e2e` — Playwright: дымовой сценарий и axe в Chromium, Firefox, WebKit и на телефоне (задача `e2e` в CI, в `check` не входит). `npm run links` — внешние картинки и видео, еженедельно в `links.yml` (A7).
