## Что есть
- **Приложение** (Vite + React + TS, GitHub Pages: https://shoralbrt.github.io/dota-lore-map/): интро, мир, регион, место, галерея, поиск героев, регионов и мест, нити со стрелками и значками событий, значимость мест, список мест в панели региона, профиль героя, чип героя, обратная связь через форму issue GitHub, экран ошибки вместо пустой страницы, RU/EN, частицы и звук, адаптив (телефон: список регионов и нижняя шторка), клавиатура, WCAG AA, reduced motion. Эпики E3–E13, E15–E16 закрыты; E17 — осталась #75.
- **Данные:** 27 регионов, 181 место, 127 героев, 409 алиасов, тексты RU/EN у всех регионов и мест, 28 медиа в галерее (15 комиксов, 4 трейлера, 3 арта событий, 6 карточек Artifact; медиа у 10 регионов из 27 — [research/E1-media-sources.md](research/E1-media-sources.md)). Схема мира `map/layout.json` согласована 2026-11-11.
- **E14 (сверка лора):** партии 01–13 слиты (127 героев из 127), односторонние связи прошлых партий разобраны (#150), имена героев в текстах мест сверены со связями (#161). Комиксы пройдены (#60, [research/E14-comics.md](research/E14-comics.md)). Счётчики: связей 256, путей 18, связей героев 87, профилей 127, кандидатов в места 20 (отклонённые в #59). Хвост комиксов (#155) разобран в research/E14-comics.md.
- **Карта:** растровый арт мира 1:1 (#163): два материка, ярусы в углах, разметка подогнана под рисунок (`map/art/`, `public/art/`). Свободная камера (#165): арт во весь кадр, перетаскивание, колесо, щипок, клавиши. Подписи, подсветка и облака подогнаны под рисунок, кадр региона — по правилу габарита (#112, SPEC §8.6). Атмосфера над артом (#167): облака с параллаксом, туман, свечение ярусов, зерно — сила от приближения (A9). Детальных картинок регионов нет — по решению владельца не обязательны. Пирамида тайлов (#164): скрипты и ленивый слой есть, тайлы появятся после дорисовки плиток владельцем.
- **Проверки:** `npm run check` — 439 тестов vitest + 18 Python, бандл 279 КБ gzip + шрифты 100 КБ (бюджет 600 и 3 МБ). `npm run e2e` — Playwright: дымовой сценарий и axe в Chromium, Firefox, WebKit и на телефоне (задача `e2e` в CI, в `check` не входит). `npm run perf` — плавность камеры, `-- --load` — FCP/LCP/CLS, бюджеты A14 (#185, #186; в `check` не входит). `npm run links` — внешние картинки и видео, еженедельно в `links.yml` (A7). Превью для соцсетей — `public/og.png` (`scripts/og-image.mjs`), лицензия кода и текстов — MIT (`LICENSE`). Коммиты и версии — стандарт habze (A7): squash, заголовок PR по Conventional Commits, версии ведёт release-please.

## Решения, принятые после SPEC
- В1: герои без места в лоре → регион «Неизведанные земли». В5: Dragon's Blood — только медиа. В8: 27 регионов (Skywrath на материке, #158). В9: «Срединные королевства» — отдельный регион в центре. В10: сторона по положению на схеме (`sideBasis`). В4: объёмные ориентиры — после MVP.
- В2: hash-адреса (A5). В6: Cormorant SC + Manrope (A8). В7: портреты с CDN Valve (A6).
- Имена героев в русских текстах — латиницей; личные имена персонажей — кириллицей.
- Медиа и арты профиля: только официальные материалы Valve, по ссылке, без копирования (A3, A6); комикс в галерее — одна страница и ссылка «читать целиком»; арт карточек Artifact — медиа места, названного на карточке, не источник лора (2026-11-17).
- Мир на телефоне — карта во весь экран с жестами, список регионов в шторке (#196, решение владельца 2026-11-19; до #196 — список под картой, #39).
