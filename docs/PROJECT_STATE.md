## Решения, принятые после SPEC
- В1: герои без места в лоре → регион «Неизведанные земли».
- В5: Dragon's Blood — только медиа.
- В2: адреса через hash — ARCHITECTURE A5.
- В7: портреты с CDN Valve — ARCHITECTURE A6.
- В8: оставляем 26 регионов. В9: «Срединные королевства» остаются отдельным регионом в центре материка.
- Имена героев в русских текстах — латиницей, как в официальном списке и русском клиенте; личные имена персонажей — кириллицей (Райлай, Трездин).
- Схема мира `docs/map/schema.svg` согласована владельцем 2026-11-11 (SPEC §9 п. 2) — основа для генерации арта.
- Медиа: картинки не копируем в репозиторий, ссылаемся на CDN Valve (как портреты, A6); страницы комиксов — на языке интерфейса; в галерее одна страница комикса + явная ссылка «читать целиком» (решение владельца 2026-11-11).
- В4: объёмные ориентиры (уровень A) — после MVP (решение владельца 2026-11-11); MVP — уровень B.
- В10: сторона по положению на схеме E2 — Radiant 8 регионов, Dire 10, нейтральных 8 (ярусы, экваториальный пояс Квойдж/Хазадал/Срединные королевства, Неизведанные земли); поле `sideBasis` в `regions.json`.

## Открытые вопросы
- Финальный арт карты: инструменты Claude не генерируют растровые изображения. До арта используется процедурная заглушка (ARCHITECTURE A4); промпты и основа для img2img — `docs/map/ART-PROMPTS.md`, `docs/map/schema-base.svg`. После арта полигоны подгоняются правкой `map/layout.json`.
