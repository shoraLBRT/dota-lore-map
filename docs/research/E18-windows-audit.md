### 1.3 Стопка и Esc

Что лежит поверх чего, сверху вниз, и куда ведёт Esc (A11): окно обратной связи → галерея → поле поиска → меню языка / «О проекте» (свои обработчики) → шторка «Регионы» (новое) → профиль → выбранный герой → уровень вверх (место → регион → мир). Каждое нажатие закрывает одно, верхнее окно.

## 3. Вопросы владельцу

**В1. «Назад» из профиля героя.** Портрет открывает профиль одной записью истории (`?hero=<k>&profile`), поэтому «назад» возвращает к экрану без героя, а не к чипу, как написано в SPEC §6.8.
- а) Оставить одну запись (сейчас так; сценарий «мир → регион → место → герой → назад ×3» приводит в мир) и поправить SPEC: «назад» — к экрану до выбора героя, Esc и крошка — к чипу. **Рекомендую.**
- б) Две записи: сначала «герой выбран», затем «профиль открыт» — «назад» закрывает профиль и оставляет героя, но из профиля в мир — на одно «назад» больше.

**В2. Клик по пустому месту карты в месте (S3 → S2).** Со свободной камерой (#165) по карте чаще кликают и дважды кликают, чтобы приблизить.
- а) Оставить как есть (одно действие назад, правило «клик мимо закрывает верхнее окно»). **Рекомендую.**
- б) Оставить, но двойной клик — только зум, без возврата в регион (клик ждёт ~250 мс, не второй ли он).
- в) Убрать: назад из места — только крошка, Esc и «назад» браузера.

**В3. Поиск и перетаскивание карты.** Начало перетаскивания уводит фокус из поля, и поиск закрывается.
- а) Оставить (поиск открывается снова одним кликом, набранное короткое). **Рекомендую.**
- б) Не закрывать поиск, пока тянут карту, — закрывать только тапом вне поля и Esc, как окно обратной связи.

**В4. Тап по карте при открытой шторке «Регионы» (телефон).** Сейчас тап открывает регион под пальцем, шторка не сворачивается.
- а) Оставить (решение #196: тап открывает и закрывает шторку только по ручке). **Рекомендую.**
- б) Первый тап по карте при развёрнутой шторке только сворачивает её («клик мимо закрывает верхнее окно»), второй — открывает регион.
