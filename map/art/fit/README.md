Подгонка `map/layout.json` под арт мира (#163, 2026-11-18). Разовые скрипты: перезапуск перепишет ручные правки (ниже).

Вход — разметка до #163 (кадр 16:10, `git show bc05afd:map/layout.json`), выход — квадратный `map/layout.json`.
`<tmp>` — любая рабочая папка.

```
ffmpeg -i map/art/world.jpg -vf scale=1000:1000 -f rawvideo -pix_fmt rgb24 <tmp>/w1000.rgb
node map/art/fit/mask.cjs <tmp>                         # маска суши по цвету, компоненты → lab.bin/lab.json
node map/art/fit/fit.cjs <tmp> <tmp>/layout.orig.json   # перенос y' = (y·1000 + 290) / 1600, берега → контур, ярусы в углах
node map/art/fit/overlay.cjs <tmp> <tmp>/layout.orig.json.fit.json   # наложение ov.rgb и отклонение берегов
node map/art/fit/finalize.cjs <tmp>/layout.orig.json.fit.json map/layout.json   # камеры и запись
```

- `mask.cjs`: вода — синеватая и тёмная (`b − (r+g)/2 > 12` и яркость < 75), затем двойной фильтр большинства. Номера компонент (север 27, юг 35, острова 31, 33, 39) зашиты в `fit.cjs`.
- `fit.cjs`: береговое ребро — не общее с соседом того же материка; прогон береговых рёбер заменяется контуром маски (Дуглас — Пекер, до 30 вершин на регион), стыки с соседями ставятся на ближайшую точку берега. Внутренние вершины, попавшие в море, сдвигаются на сушу; граница Skywrath сдвинута западнее (регион появился после основы арта).
- `places.cjs`: места ярусов — в эллиптических координатах от угла; места материка — внутрь полигона и на сушу, слипшиеся раздвигаются.
- Руками после скриптов: столица Stonehall и озеро Lightglass — на нарисованный город и озеро, подпись Преисподних — выше нижнего края.
